# วิธีต่ออุปกรณ์ในห้องฝึก Studio Room 01

คู่มือนี้อธิบายเส้นทางที่ใช้ผ่านด่าน `studio-full` ตามพอร์ตและสายที่เกมรองรับอยู่จริง การต่อและภาพ/เสียงที่แสดงในเกมเป็นการจำลอง ไม่ได้สั่งงานอุปกรณ์จริงหรือรับเสียงจากไมโครโฟนของคอมพิวเตอร์

## วิธีหยิบและเสียบ

1. ใช้ `E` หยิบอุปกรณ์หรือสายที่เล็งอยู่ ใช้ `F` วางบนโต๊ะทำงานกลางห้อง
2. วาง HDS7105, Audio Mixer, Magewell, HP Notebook, Sennheiser XS 1, COMICA RX, TX 1 และ TX 2 บนโต๊ะกลางก่อนต่อพอร์ตของอุปกรณ์เหล่านี้
3. เล็งปลายสายแล้วกด `E` เพื่อถือทั้งเส้น จากนั้นเล็งพอร์ตปลายทางแล้วกด `E` เพื่อเสียบ ถ้าต้องการหยิบแค่ปลายสาย ใช้ `1 + E` หรือ `2 + E`
4. ไมค์หนีบปกเป็นชุดไมค์กับสายติดกัน หยิบที่หัวไมค์ด้วย `E` แล้วนำปลั๊ก 3.5 มม. ไปเสียบ TX

## เส้นทางที่ผ่านด่าน

TX ส่งเสียงไป RX แบบไร้สาย จึงไม่มีสายระหว่างสองอุปกรณ์ ช่อง XLR INPUT ของ Yamaha HS5 เป็นทางเลือกแทน TRS INPUT โดยใช้สาย XLR จาก Mixer XLR LINE OUTPUT ห้ามใช้ช่องขับลำโพงกำลังสูงของ Mixer กับลำโพง Active รุ่นนี้

PGM OUT เป็นพอร์ตเดียว หากใช้ต่อ Magewell เพื่อผ่านด่าน ให้ใช้ MULTIVIEW OUT ต่อทีวี หากต้องการให้ทีวีแสดง Program สามารถย้ายสาย PGM ไปทีวีได้ แต่จะไม่มีสัญญาณเข้าตัว Capture Card พร้อมกันโดยไม่มีอุปกรณ์แยกสัญญาณ

## ขอบเขตการจำลอง

- ช่องสัญญาณที่เป็นเป้าหมายในห้องฝึกต่อได้ตามชนิดหัวสายและทิศทาง INPUT/OUTPUT ที่เกมกำหนด
- เสียงพูด, การจับคู่ไร้สาย, ภาพกล้อง และ OBS เป็นสถานะจำลองในเกม ไม่ใช่ภาพหรือเสียงสดจากอุปกรณ์จริง
- ขนาดและผิววัสดุของบางโมเดลประมาณจากภาพอ้างอิง ยังไม่ใช่ไฟล์ CAD หรือข้อมูลขนาดที่ยืนยันจากผู้ผลิต
