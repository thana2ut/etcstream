## นโยบายต่อห้อง
- **ห้องเรียน / สตูดิโอ:** ห้องปิด เงาเดียว ไฟเสริม point light ไม่มีเงา
- **หอประชุม:** แชนเดอเลียร์/ดอกไม้เป็น instanced · ไฟ track เป็น mesh emissive (ไม่ใช่ light จริง)
- **ภายนอก:** fog + ท้องฟ้าทรงกลมเดียว · ต้นไม้/รั้ว/กรวย instanced · อาคารด้านหลังเป็น mesh เรียบ
- **สนามกีฬา:** อัฒจันทร์/ที่นั่ง instanced · สนามจริงอยู่นอกพื้นที่เดิน (ไม่มี collider) · ห้องควบคุมมีไฟ 3 ดวง

## การเดินและการเข้าถึง (ตามการออกแบบ ยังไม่ตรวจในเกม)
- ขอบเขต collider = ขอบเขตผัง = เปลือกฉาก (ขยายด้วย `VENUE_SCALE` เดียวกัน)
- เฟอร์นิเจอร์คงขนาดจริง ทางเดินจึงกว้างขึ้นตามสเกล · โต๊ะผลิตสตูดิโอเดินรอบได้ทุกด้าน
- จุดเกิดอยู่ที่ประตู/ทางเข้า (พื้นที่ว่าง)
- พอร์ตวางด้านหน้าอุปกรณ์ฝั่งผู้เล่น · ตู้ Rack: พอร์ตหน้าเครื่องหันเข้าทางเดิน Rack

## ความเสี่ยงที่ทราบ (ยังไม่ได้ตรวจ)
- สนามกีฬาระดับ 5: พอร์ต ~110 จุด + สาย 54 เส้น — แต่ละพอร์ต subscribe store หลายตัว อาจหนักบนเครื่องช้า
- ไฟ point light ที่เพิ่มในห้องเรียน/หอประชุม (ไม่มีเงา) เพิ่มต้นทุน shading เล็กน้อย
- อุปกรณ์ที่วางจาก `EXTRA_PLACES` อาจซ้อนเฟอร์นิเจอร์หรือ collider บังการเข้าถึง
- สายยาว (สนามกีฬา/ภายนอก) ยังต้องถือเดินจากปลายถึงปลาย — ยังไม่มีจุด patch/reel
- ยังไม่มี LOD สำหรับโครงสร้างสนามระยะไกล นอกจาก fog
