กราฟคำตอบจริงอยู่ใน `stage.solution` แล้วแปลงเป็น `scenario.canonical`; การเพิ่มตัวเลือกสายไม่เปลี่ยนกราฟ เงื่อนไขผ่าน รหัสพอร์ต หรือการเซฟเดิม

## หลักการร่วม

1. ต่อ OUTPUT → INPUT โดยชนิดหัวและระดับสัญญาณต้องรองรับ; HDMI/SDI ข้ามชนิดต้องผ่านตัวแปลงที่เปิดใช้งาน
2. USB DEVICE → USB HOST ด้วยสายข้อมูล; RF ใช้การจับคู่ ไม่ใช่สาย RF
3. Optical ต้องมีคู่ TX/RX และไฟเลี้ยง; Multiview แยกจาก Program
4. เสียงต้องผ่านบัส/การฝังเสียงที่ถูกต้องก่อนถึงปลายทาง; สายอย่างเดียวไม่ถือว่าระบบพร้อม
5. สาย `CTRL-REPLAY` เป็นลิงก์ควบคุมจำลอง ไม่ใช่ของกายภาพในกระเป๋า
6. ทดสอบและตรวจรับจากกราฟปัจจุบันใหม่เมื่อถอดสายหรือเปลี่ยนค่าควบคุม; สนามกลางแจ้งยังต้องผ่าน GO/NO-GO
