# ป้ายคำสั่งบรรทัดเดียว และปรับตำแหน่งมือ

วันที่: 2026-10-20 · ยังไม่ได้ commit · ไม่ได้ทดสอบตามคำขอ

## 1. คอมโพเนนต์ป้ายคำสั่งที่ปรับ
- `components/game/training-hud.tsx`: `.prompt-action-pill` เพิ่ม `title` ให้แสดงข้อความเต็มเมื่อชี้
- `app/xianxia-theme.css`: ชุด CSS ป้ายคำสั่ง (ต่อท้ายไฟล์)

## 2. การบังคับให้อยู่บรรทัดเดียว
ใช้ `white-space: nowrap` ทั้งกรอบ ข้อความไม่ขึ้นบรรทัดสองอีกต่อไป ถ้ายาวเกินความกว้างสูงสุด จะตัดท้ายด้วย `…` เป็นทางเลือกสุดท้าย และดูข้อความเต็มได้จาก tooltip ปุ่ม `E` ยังอยู่ซ้ายและจัดกึ่งกลางแนวตั้ง

## 3. ขนาดกรอบและตัวอักษร
| ส่วน | เดิม | ใหม่ |
|---|---|---|
| ความสูงกรอบ | 44 px | 36 px |
| ตัวอักษร | .92rem | .84rem |
| ปุ่ม `E` | 30 px | 26 px |
| ระยะบรรทัด | — | 1.3 (สระ/วรรณยุกต์ไทยไม่ถูกตัด) |

## 4. ตำแหน่งมือ
มือทั้งสองข้างเข้าใกล้กันขึ้นเล็กน้อยผ่าน `--fp-hand-gap = max(236px, 13.5vw)` รายละเอียดอยู่ใน `FIRST_PERSON_HAND_POSITION_AND_MOTION_REFINEMENT_TH.md`

## 5. การกันมือบังป้าย
ความกว้างสูงสุดของป้าย = `min(2 × --fp-hand-gap − 16px, 92vw)` ใช้ตัวแปรเดียวกับระยะมือ ถ้าปรับระยะมือภายหลัง ป้ายก็จะปรับตามเอง จึงไม่ล้นเข้าไปใต้มือ

## 6. การเคลื่อนไหวของมือ
ยังคงหายใจ ส่าย และหน่วงตามเมาส์ และเพิ่มการแกว่งขณะเดิน

## 7. ระบบที่ได้รับผล
ป้ายคำสั่งกลางจอและมือ ในทุกห้องรวมห้องฝึกอิสระ ส่วนป้ายแสดงสิ่งที่ถืออยู่ (`prompt-holding-pill`) ไม่ได้แก้

## 8. ข้อสังเกต
- ที่จอ 1366 px ป้ายกว้างสูงสุดประมาณ 456 px ชื่ออุปกรณ์ที่ยาวมาก เช่น `หยิบอุปกรณ์ Audio Mixer (YAMAHA PMX-402D-USB) · กดค้าง 2 วิ ดูรายละเอียด` อาจถูกตัดท้าย ถ้าไม่ต้องการให้ตัด ต้องย่อข้อความคำสั่ง เช่น ตัดรหัสในวงเล็บออก
- โหมดสัมผัสยังใช้กฎขนาดเฉพาะของตัวเอง
