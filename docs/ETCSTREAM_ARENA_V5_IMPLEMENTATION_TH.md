## 2. สิ่งที่พบจากคลิปล่าสุดและแนวทางที่ลงมือแก้

หน้าเดิมปรับความสม่ำเสมอมาบ้างแล้ว แต่ยังใช้ภาพแบนเนอร์กว้าง กล่องโปรไฟล์ การ์ดสี่ช่อง และแผงฟอร์มซ้อนในแนวตั้ง ทำให้ภาพรวมคล้ายเว็บไซต์จัดการข้อมูล ภาพโลกเกมอยู่หลังกล่องจำนวนมาก หน้าเพื่อนซ้ำข้อความไม่มีรายการสามกล่อง และหน้าเลือกภารกิจยังพึ่งตัวเลือกแบบฟอร์มสองช่องเป็นหลัก

V5 จัดองค์ประกอบเป็นสามชั้น: ฉากโลกเดิมที่มองเห็นมากขึ้น แถบเมนูเกมร่วมชุดเดียว และพื้นที่ใช้งานที่มีหน้าที่เฉพาะ เช่น ประตูภารกิจ ใบภารกิจ ศิลาทำเนียบ สมุดสหาย และแผ่นข้อมูลผู้ฝึก ใช้ภาพใน `public/assets/arena/` เดิมทั้งหมด ไม่มีการดาวน์โหลดหรือสร้างงานภาพมาแทน

## 3. ก่อนและหลังรายหน้า

| หน้า / สถานะ | โครงสร้างที่ลงมือปรับใน V5 |
|---|---|
| `/arena` | เปลี่ยนการ์ดภาพย่อยสี่ใบเป็นประตูภารกิจแบบภาพเต็มพื้นหลัง เรียงสองคอลัมน์บนจอกว้าง ข้อความซ้อนบนไล่สีเข้ม ปรับข้อมูลผู้ฝึกให้เป็นแถบโปร่งขนาดเล็ก ลดแบนเนอร์ภาพซ้ำ ให้บททดสอบกาลเวลาอยู่ก่อนโหมดอื่น รายละเอียดการยืนยันผลอยู่ในส่วนกดอ่านเพิ่ม |
| `/arena/time-attack` | เปลี่ยนตัวเลือกสถานที่เป็นปุ่มห้าสถานที่จากแค็ตตาล็อกจริง ระดับ 1–5 เป็นตราเลือกที่มีสถานะ `aria-pressed` แสดงภารกิจที่เลือกเป็นใบงานเด่นพร้อมวัตถุประสงค์ ด้านข้างเป็นภาพนาฬิกาทรายและขั้นเตรียมตัวสามข้อ การเลือกสถานที่/ระดับเปลี่ยนเฉพาะข้อมูลที่แสดง ไม่ส่งคำขอเริ่มรอบ |
| `/arena/duel` | เปลี่ยนแผงประกาศเป็นประตูประลองที่ยังถูกผนึก มีภาพกระบี่ ตราประตู และข้อความสถานะตรงไปตรงมา เหตุผลทางเทคนิคอยู่ในส่วนกดอ่านเพิ่ม ปุ่มเริ่มยังปิด และมีลิงก์ไปโหมดกาลเวลาจริง |
| `/arena/leaderboard` | จัดตัวกรองเป็นแถบเดียว สถานะไม่มีอันดับมีภาพศิลาจารึกและคำแนะนำ โดยไม่ใส่ชื่อหรือคะแนนจำลอง ตารางเดิมใช้ข้อมูลจริงจากเซิร์ฟเวอร์ เพิ่มชื่อสถานที่ในคำอธิบายตาราง และปุ่มลองโหลดใหม่เมื่อข้อมูลผิดพลาด |
| `/arena/friends` | แถวแรกเป็นช่องเชิญและป้ายรหัสประจำตัวที่คัดลอกได้ ด้านล่างเป็นสมุดรายชื่อเดียวที่สลับสหาย/คำขอรับ/คำขอส่ง จำนวนมาจากรายการจริง ข้อความว่างต่างกันตามบริบท รายชื่อสาธารณะและรหัสปิดกั้นอยู่ในส่วนขยายอ่านเพิ่ม คงคำสั่งรับ ปฏิเสธ ยกเลิก เลิกเป็นสหาย ปิดกั้น และเลิกปิดกั้นตาม API เดิม |
| `/arena/profile` | รวมตรา ชื่อ รหัสสหาย และสถิติสี่ค่าเป็นแผ่นข้อมูลผู้ฝึกเดียว ลดความสูงกล่องสถิติ ใต้ลงมาเป็นการตั้งค่ากับประวัติสองฝั่ง ปุ่มบันทึกเด่นชัด ค่าเวลาที่ไม่มีและตัวนับที่ API ไม่ระบุแสดงขีด ไม่สมมติเป็นศูนย์ |
| ใบงานก่อนรอบ | เพิ่มชื่อสถานที่/ภารกิจและรหัสด่าน แยกสถานะรอบกับเวลา แสดงเวลาที่เทียบกับเวลาเซิร์ฟเวอร์หากรอบเดินแล้ว ข้อความใบงานเดิมเรียงเป็นแถวลำดับ ไม่มีการเปิดกราฟเฉลยเพิ่มเติม |
| แถบสถานะขณะเล่น | ปรับกรอบ สี เวลา และลำดับปุ่มของแถบแข่งขันเดิม แยกปุ่มส่งผลกับยุติรอบ ใช้หน้าต่างยืนยันชุดเดียวกับหน้าใบงาน และหยุดรับปุ่มลัดกระเป๋า/คอนโซลระหว่างยืนยัน โดยไม่ได้หยุดเวลาแข่งขันฝั่งเซิร์ฟเวอร์ |
| ผลรอบ / ยุติรอบ | เพิ่มตราผลลัพธ์ สถานะและเวลาจริงสามช่อง รอบ DNF ใช้สีเป็นกลาง ไม่มีภาพชนะ รอบก่อนเริ่มแสดงว่าไม่ได้เริ่มจับเวลา ตราถ้วยใช้เฉพาะสถานะ VERIFIED ที่ได้รับจากระบบ ไม่ตั้งสถานะนั้นเอง มีทางกลับเลือกด่าน ประวัติ และหอประลอง |
| กำลังโหลด / ผิดพลาด | ใช้แผงสถานะและตรากำลังโหลดร่วมกัน แยกข้อผิดพลาดจากข้อมูลว่าง หน้าเปิดรอบไม่ได้มีทางกลับ และรหัสสหายที่ไม่มีจะไม่ให้กดคัดลอก |

## 4. รายการไฟล์ที่แก้

1. `app/arena/arena.css` — องค์ประกอบฉาก V5 โทนหมึก/ทอง/หยก กรอบมุม ปุ่ม ประตูภารกิจ ตัวเลือกด่าน ศิลาทำเนียบ สมุดสหาย แผ่นข้อมูลผู้ฝึก ตราผลลัพธ์ และกฎจัดวางตามความกว้างจอ สไตล์หน้าสาธารณะผูกกับ Arena ไม่ได้เปลี่ยน CSS ทั่วเว็บไซต์
2. `components/arena/shell.tsx` — ระบุฉากปัจจุบันจากเส้นทางเดิม เมนูมือถือกด Escape แล้วคืนโฟกัส แสดงชื่อเต็มผ่านคำอธิบายลิงก์ ปรับหัวหน้าให้สั้นลงและไม่โหลดภาพหัวหน้าแรกที่ไม่ได้ใช้ ปรับการแสดงค่าว่างและการคัดลอกรหัส เพิ่มรหัสอ้างอิงเฉพาะและการจัดโฟกัสในหน้าต่างยืนยัน
3. `components/arena/portal.tsx` — โครงสร้างทั้งหกหน้าหลัก ตัวเลือกสถานที่และระดับแบบเกม กรอบผนึก Duel สถานะไม่มีอันดับ การสลับรายการสหาย และแผ่นข้อมูลผู้ฝึก ใช้เส้นทางและ payload ของ API เดิม
4. `components/arena/play.tsx` — หน้ากำลังโหลด/เปิดรอบไม่ได้ ใบงานพร้อมสถานะเวลา ชื่อสถานที่และภารกิจ ตราผลรอบ แถบสถานะแข่งขัน และหน้าต่างยืนยันยุติรอบ

ไม่ได้เพิ่ม component package หรือ dependency ใหม่ ไฟล์ทั้งสี่มีอยู่แล้วก่อน V5 ไม่ใช่การสร้างระบบ Arena ใหม่จากศูนย์

## 6. ระบบเดิมที่รักษาไว้ในซอร์ส

- Welcome และภาพพื้นหลัง/ปุ่มเดิม, Academy, ห้องฝึกอิสระ, Mission Hall และ 25 ภารกิจ
- อุปกรณ์จริง ชื่อพอร์ต ชนิดสาย เงื่อนไขต่อสัญญาณ การตั้งค่า กระเป๋า ระบบเดิน กล้อง และการบันทึกความก้าวหน้า
- API และเซสชันผู้เล่น การเป็นเจ้าของรอบแข่งขัน รหัสสหาย ความยินยอมเปิดเผยรายชื่อ/ออนไลน์ และการล็อกชื่อโดยผู้ดูแล
- เวลาเริ่มและผลรอบจากเซิร์ฟเวอร์ คิวเหตุการณ์บทลงโทษ การป้องกันส่งคำสั่งซ้ำ การตรวจความสำเร็จ และการคืนสถานะฝึกเดิมเมื่อออก
- นโยบายไม่จัดอันดับผลที่ยังไม่ยืนยันและผลยุติรอบ ไม่เพิ่มข้อมูลจำลองหรือระบบยืนยันผลทางลัด
- `/admin` เป็นประตูผู้ดูแลเดิม ไม่มีการให้สิทธิ์ตามชื่อเล่น ไม่มีการแก้ระบบยืนยันตัวตนหรือเพิ่มเครื่องมือผู้ดูแลในเมนูสาธารณะ
- ไม่แก้เซิร์ฟเวอร์ ฐานข้อมูล migration seed `.env.local` หรือข้อมูลผู้เล่น ไม่ commit, push หรือ deploy

## 7. ข้อจำกัดที่ต้องทราบ

1. Duel ยังปิดอยู่จริง ไม่มีระบบจับคู่ ห้องต่อสู้ คู่แข่งจำลอง หรือผู้ชนะจากงานนี้
2. ผลส่งของ Time Attack ปัจจุบันยังเป็น UNDER_REVIEW ตามระบบเดิม การตกแต่งหน้าไม่ได้ทำให้ระบบตรวจย้อนกลับคำสั่งครบหรือรับรองการแข่งขันจริง
3. ไม่เพิ่มอันดับส่วนตัวหรือสถิติรายด่านที่ API ปัจจุบันไม่ได้ส่งมา ไม่สมมติว่าทุกคนออนไลน์
4. ความสมบูรณ์ของการจัดวาง การครอบภาพ การทำงานของปุ่ม ฟอร์ม หน้าต่างยืนยัน และเกมหลังปรับยังไม่ได้ตรวจในเบราว์เซอร์
5. ออกแบบกฎ responsive และลดการเคลื่อนไหวไว้ในโค้ด แต่ยังไม่ได้ตรวจขนาด 1920×1080, 1600×900, 1366×768, 1024×768, 768×1024, มือถือ หรือการซูม
6. ภาพ/ผลตรวจ V4 ที่อาจมีอยู่ในโครงการเป็นหลักฐานรุ่นก่อน **ไม่ใช้รับรอง V5**

## 9. รายการแนะนำให้ต้าตรวจด้วยตนเอง

รายการนี้เป็นงานตรวจที่ยังไม่ได้ดำเนินการ ไม่ใช่รายการที่ผ่านแล้ว

- [ ] เปิดหกหน้าหลักของ Arena ตรวจเมนูที่เลือก ทางกลับ และการย้อนหน้าของเบราว์เซอร์
- [ ] ตรวจประตูภารกิจ ชื่อ ปุ่ม และภาพบนจอคอม แล็ปท็อป แท็บเล็ต มือถือ รวมถึงเมื่อซูมและชื่อผู้เล่นยาว
- [ ] เลือกห้าสถานที่และห้าระดับตามกฎที่ระบบอนุญาต ตรวจว่าข้อมูลภารกิจเปลี่ยนตรงด่านและไม่ได้เริ่มเวลาจากการเลือกอย่างเดียว
