## สิ่งที่เปลี่ยนและสาเหตุ

ก่อนแก้ หน้า Mission Hall ยกเว้นกฎขั้นต่ำให้เข้าด้วยกระเป๋าว่าง และข้อความท้ายหน้าบอกให้ไปหยิบจากคลังได้ทันที ส่วนช่องกระเป๋ามี CSS ลดเหลือ 52 พิกเซลบนจอโน้ตบุ๊ก พร้อม ResizeObserver ที่บีบจำนวนแถวตามพื้นที่ที่เหลือ ทำให้ช่องเล็ก/พื้นที่กระเป๋าถูกบีบเมื่อข้อความยาว คำอธิบายภารกิจมีเพียงบรรทัดสั้นก่อนเจอรายละเอียดเต็มหลังจัดสาย

แก้เฉพาะหน้าก่อนเข้าห้องและ state กระเป๋าหน้านี้ ไม่แก้กราฟสัญญาณ พอร์ต นิยามภารกิจ การตรวจรับ ฉากสามมิติ หรือกติกาปลดระดับ

### ลำดับอธิบายก่อนเลือกสาย

1. ส่วนหัวแสดงห้อง ระดับ/รหัสด่าน ชื่อภารกิจ และตัวบอกขั้นตอนเดิม
2. กรอบ “อ่านภารกิจก่อนเลือกสาย” แสดงวัตถุประสงค์และสิ่งที่ต้องทำแบบไม่ตัดเป็นจุดไข่ปลา อยู่ก่อน `.cl-body` ทั้งลำดับ DOM และตำแหน่งที่วัดจาก Chrome
3. ด้านขวาของกรอบมีภาพรวมเส้นทางภาพ/เสียงตามประเภทสายที่ด่านใช้ หากมีคำแนะนำของด่านอยู่แล้ว เปิดดูรายการขั้นตอนได้จากปุ่มรายละเอียด ไม่สร้างเฉลยให้ด่านประเมินที่เดิมไม่มีคำใบ้
4. หลังอ่านแล้วจึงเลือกหมวด/ค้นหา/ดูหัวต่อ/จำนวน/ใส่กระเป๋า ส่วนบทนำเดิมหลังจัดสายยังอยู่เพื่อรักษาลำดับเริ่มเล่นเดิม

### กฎขั้นต่ำหนึ่งเส้น

- `total === 0` ปิดปุ่ม “เข้าสู่ด่าน →” ด้วย native disabled และแสดง “ใส่สายอย่างน้อย 1 เส้นก่อนเข้าสู่ด่าน” ทั้งบริเวณสถานะและท้ายหน้า
- เมื่อมีหนึ่งเส้นขึ้นไป ปุ่มเปิดและข้อความเป็น “พร้อมออกเดินทาง” พร้อมจำนวนจริง
- มี guard ใน click handler และใน onConfirm ของหน้า play จึงไม่พึ่งสี/สไตล์ disabled อย่างเดียว
- Mission Hall ยังกรองและจำกัดจำนวนตามสต็อกด่านจริงก่อนส่ง bag สายที่ติดตั้งเดิมและสายติดเครื่องไม่ถูกสร้างเพิ่มเพื่อผ่านกฎนี้
- ตรวจข้อมูล 25/25 ด่านแล้วมีสายที่เลือกได้จริง จึงไม่เกิดด่านที่ถูกบังคับขั้นต่ำแต่ไม่มีสายให้จัด (`qa-evidence/cable-ui/all-25-stock.json`)
- สายที่ยังไม่ได้จัดยังอยู่คลัง Mission Hall ตามกติกาเดิม **แต่ต้องจัดอย่างน้อยหนึ่งเส้นก่อนเข้า**; กฎนี้แทนข้อยกเว้นกระเป๋าว่างของ milestone ก่อนหน้า ไม่ได้เปลี่ยนระบบคลังในห้อง

### ขนาดกระเป๋าและรูปแบบ

นำการคำนวณความสูงแบบบีบแถวด้วย ResizeObserver ออก ใช้ช่องคงความสูง 104 พิกเซลแทน 52 พิกเซลของจอสั้น มีชื่อสาย จำนวน และปุ่มนำออกที่เห็นได้โดยไม่ต้อง hover แสดงอย่างน้อย 6 ช่อง กระเป๋าเพิ่มแถวตามชนิดที่จัดได้ ไม่ใช่การลดจำนวนชนิดที่นำไปได้จริง

วัดจาก Chrome: desktop ช่องกว้างประมาณ 122 พิกเซล; ที่หน้าจอมือถือ 390 พิกเซล ช่องกว้างประมาณ 98 พิกเซล ทั้งคู่สูง 104 พิกเซล พื้นที่กระเป๋าเลื่อนดูแถวเพิ่มเติมได้ เมื่อพื้นที่แนวตั้งน้อยใช้การเลื่อนทั้งหน้าเพื่อให้รายละเอียดและปุ่มยังอ่านง่าย ไม่ย่อช่องกลับเป็นขนาดเล็ก

## ข้อจำกัดและสิ่งที่เจ้าของลองต่อได้

- บนจอเตี้ยต้องเลื่อนหน้าเพื่อดูกระเป๋าครบพร้อมคำอธิบายยาว เป็นการรักษาขนาดอ่านง่าย ไม่ใช่หน้าที่ทุกส่วนต้องอยู่ใน viewport เดียวเสมอ
- ภาพต้นแบบใช้เป็นแนวโครง สี และสัดส่วนหลัก ไม่ใช่การจับตำแหน่งให้ตรงทุกพิกเซลทุกความละเอียด
- ทดสอบมือถือด้วย Chrome จำลองหน้าจอ ยังไม่ได้ลองทัชบนโทรศัพท์จริงหรือ gamepad
- คงกติกาการเลือกสายของห้องฝึกอิสระเดิม ส่วนสต็อกเฉพาะด่านใช้เพดานเดิมของ Mission Hall ไม่ขยายกฎคลังหรือจำลองฮาร์ดแวร์ใหม่
- ต้าลองเปิด ST-02 หรือด่านอื่น ล้างกระเป๋า → ต้องกดเข้าไม่ได้ → เพิ่มหนึ่งเส้น → ต้องเข้าได้ → นำออก/ล้าง → ต้องปิดอีกครั้ง แล้วลองเลื่อน/ค้นหาและเปิดดูแนวทางก่อนเลือกสาย

รักษาผลผ่านเดิมไว้ ไม่มีการรับรองหรือปลดด่านเพิ่มในรอบ UI นี้ และไม่ได้แก้ระบบเล่นของ Free Practice Room01
