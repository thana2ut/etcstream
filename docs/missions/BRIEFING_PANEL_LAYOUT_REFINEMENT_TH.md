# ปรับกรอบและการจัดวางหน้าใบงานทุกภารกิจ

วันที่ 20 ตุลาคม 2026

## ปัญหาจากโค้ดเดิม

กรอบ play-intro-wrapper กว้างสูงสุด 980px พร้อม padding 24px และ intro-info-card มี padding ซ้ำ 24px คอลัมน์เท่ากันแต่จัดแนวกลาง ทำให้ข้อความยาวและแผนผังไม่เริ่มในแนวเดียวกัน มี scrollbar ทั้งกรอบหลักและ intro-target-steps และปุ่มเตรียมสายอยู่ท้ายคอลัมน์รายการ จึงเสี่ยงอยู่ลึกนอกบริเวณมองเห็น ป้ายหัวข้อ/รหัสอยู่รวมกับเนื้อหายาว

## สิ่งที่แก้และไฟล์

1. `app/play/page.tsx`: ใช้กรอบร่วมเดิม เพิ่ม briefing-backdrop และ briefing-frame แยก header, briefing-body, footer จริง ย้ายปุ่มย้อนกลับ สถานที่ ชื่อภารกิจ รหัส/ระดับ ไปส่วนหัว ย้ายปุ่ม “เตรียมสาย” ลงแถบล่างซึ่งอยู่นอกพื้นที่เลื่อน เนื้อหาและภาพรวมอยู่ใน body ที่โฟกัสด้วยคีย์บอร์ดได้
2. `app/xianxia-theme.css`: เพิ่มกฎที่จำกัดเฉพาะ briefing-frame ไม่แก้ dialog อื่น กรอบกว้างไม่เกิน 1180px สูงไม่เกิน 840px และไม่เกินพื้นที่ผู้เล่นมีจริง เผื่อ safe area 16px (จอเล็ก/เตี้ย 8px) ตรงกลางหน้าจอ ใช้ grid แถว auto / minmax(0,1fr) / auto จึงแยกส่วนหัวและปุ่มจากบริเวณเลื่อนได้
3. `docs/missions/BRIEFING_PANEL_LAYOUT_REFINEMENT_TH.md`: รายงานนี้

## สมดุลเนื้อหาและแผนผัง

- คอลัมน์ซ้ายต่อขวา 1.2:1 ใช้ minmax(0,...) ไม่บังคับความกว้างตามข้อความยาว จัดแนวด้านบน ระยะห่าง 24px ลด padding ซ้ำของคอลัมน์ซ้าย
- ข้อความทั่วไป 1rem ระยะบรรทัด 1.8 รายการ .95rem ข้อความรอง .88rem และตัดบรรทัดได้ ไม่ใช้ ellipsis ตัดคำ
- แผนผังมีกรอบเฉพาะ อยู่แนวบนและ sticky ภายในพื้นที่เลื่อนของเดสก์ท็อป ปรับแต่ละโหนดเป็นคอลัมน์ยืดหยุ่น ชื่อ .95rem รายละเอียด .85rem ไม่ยึดความกว้างโหนดเดิม 112px
- ที่ความกว้างไม่เกิน 860px เปลี่ยนเป็นคอลัมน์เดียวและเลิก sticky; ไม่เกิน 560px ผังเรียงลงแนวตั้ง ลูกศรหมุนตามทิศทาง เพื่อไม่บีบสามโหนดให้เล็ก
- รายการเตรียมยกเลิก max-height/overflow ภายใน ใช้ scrollbar เฉพาะ body เพียงหนึ่งพื้นที่ ปุ่มด้านล่างยังแยกอยู่เสมอ
- ปุ่มเตรียมสายมีความสูงขั้นต่ำ 48px จอเล็ก/เตี้ยซ่อนเฉพาะข้อความอธิบายซ้ำข้างปุ่ม ไม่ซ่อนปุ่ม ข้อมูลใบงานยังอยู่ในพื้นที่เนื้อหา
- backdrop ทึบขึ้นและเป็นชั้นเดิมเหนือหัวเกม ไม่ย้าย header เกมหรือเปลี่ยนระบบปุ่มในห้องเล่น

## ผลตรวจ

- อ่านโครงสร้าง JSX จริงและ CSS เดิมที่ cultivation-theme.css / xianxia-theme.css รวม breakpoint ก่อนเพิ่มกฎเฉพาะกรอบ
- ตรวจ source ของ header/body/footer, grid minmax, scroll region และตำแหน่ง action แล้ว
- `npm run lint`: ผ่าน
- `npm run build`: ผ่าน รวม TypeScript และ static routes
- `git diff --check`: ผ่าน
- ตรวจ branch/status แล้ว มีงานค้างจากรอบก่อนซึ่งเก็บไว้ ไม่ commit/push ไม่แตะไฟล์ลับหรือข้อมูลผู้เล่น
- ไม่เพิ่มชุดทดสอบที่ตรวจซ้ำค่า CSS และไม่ได้รันชุด simulation ซ้ำ เพราะรอบนี้แก้โครงสร้างแสดงผลและ CSS เท่านั้น

## ข้อจำกัดและตรวจต่อด้วยมือ

รอบนี้ยังไม่เปิดเบราว์เซอร์ จึงไม่อ้างว่าเห็นผลการจัดวางจริง/ไม่มี overlap ทุกความละเอียด การ build ตรวจไวยากรณ์และชนิดข้อมูล ไม่ยืนยันรูปลักษณ์

ให้ตรวจตัวแทน XS-01, ST-02, AU-01, OUT-03, SP-05 และห้องฝึกอิสระที่ 1920×1080, 1366×768, 1280×720 และจอมือถือ:

1. กรอบอยู่กลางจอ ไม่บังปุ่มย้อนกลับ ชื่อ/รหัส/ระดับอ่านครบ และไม่ชิดขอบ
2. เลื่อนรายการยาวของด่านระดับสูง เนื้อหามีพื้นที่เลื่อนเดียว ปุ่มเตรียมสายยังมองเห็นและกดได้
3. ผังสัญญาณสามขั้นไม่ล้นกรอบ คำไทยยาวและวรรณยุกต์ไม่ถูกตัด จอเล็กเรียงลงถูกทิศ
4. ใช้ Tab โฟกัสพื้นที่เนื้อหาแล้วเลื่อนด้วยคีย์บอร์ด ตรวจปุ่มเตรียมสายและย้อนกลับ
5. ทดลองขยายตัวอักษร/ซูม 200% และแนวนอนที่เตี้ยมาก ส่วนหัวที่ยาวมากอาจกินพื้นที่ body มาก ต้องตรวจด้วยตาและปรับเพิ่มหากพบจริง
6. กดเตรียมสาย เลือกสาย เข้าห้อง และลองใหม่ ยืนยันลำดับเดิมกับข้อมูลผ่านด่านสะสม

กรอบร่วมแก้จากโค้ดครบทั้งห้าสถานที่แล้ว แต่การรับรองความสวยงาม ความสมดุล และการอ่านในภาพจริงยังรอการตรวจด้วยมือ
