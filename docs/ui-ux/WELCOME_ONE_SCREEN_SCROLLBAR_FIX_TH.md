# แก้หน้า Welcome ให้พอดีหนึ่งหน้าจอ — 20 ตุลาคม 2026

## ขอบเขตและไฟล์
แก้เฉพาะหน้า Welcome ไม่มีการแก้ข้อมูลผู้เล่น ระบบแข่งขัน ผู้ดูแล ภารกิจ หรืออุปกรณ์ 3D
- app/page.tsx: เพิ่มคลาส welcome-page เฉพาะสถานะ welcome ไม่เปลี่ยน event handler หรือ route
- app/app-shell.css: ลบกฎ max-height/overflow ของ welcome-hero-card ที่เพิ่มเมื่อมีปุ่มแข่งขัน
- app/xianxia-theme.css: เพิ่มกฎจัดวางเฉพาะ welcome-page

ไฟล์สร้าง: รายงานนี้ และ docs/qa-evidence/welcome-viewport/desktop-results.json, welcome-1366x650.png, welcome-final.png

## สาเหตุที่ตรวจพบ
1. แถบเลื่อนในการ์ด: .welcome-hero-card มี max-height:calc(100dvh - 140px), overflow-y:auto แต่ตัวอักษร ระยะห่าง และปุ่มเพิ่มใหม่ทำให้เนื้อหาสูง 659px ที่ viewport ประมาณ1536×674 ขณะที่ clientHeight ของการ์ดเหลือ534px จึงเลื่อนจริง
2. ชั้นครอบหน้า: .fantasy-viewport:not(.game-screen) ตั้ง overflow-y:auto อีกชั้น แยกจากการ์ด เป็นเจ้าของ scroll container ชั้นนอกที่ซ้ำกับด้านใน แก้เฉพาะ .welcome-page ให้เป็นเนื้อหาใน viewport และไม่สร้าง scroll container ชั้นนอกสำหรับ desktop

ข้อเท็จจริงก่อนแก้: ในสถานะ1536×674ที่วัดได้ main มี scrollHeight เท่ากับclientHeight จึงยืนยันแถบด้านในที่ล้นได้โดยตรง แต่ไม่ได้จับภาพสองแถบพร้อมกันก่อนแก้ ไม่อ้างว่าได้ทำซ้ำภาพอ้างอิงทั้งสองแถบทุกสภาวะ ภาพวันที่20ตุลาคมไม่ได้แนบเป็นไฟล์ภาพแยกในคำขอล่าสุด จึงใช้หน้าจริงที่เปิดอยู่เป็นหลักฐานตรวจสอบ

## การจัดหน้า
- โลโก้58×48px; ชื่อใช้clampและตัดบรรทัดได้โดยไม่ตัดข้อความ
- ปุ่มสองปุ่มหลักสูง50px ปุ่มเปลี่ยนชื่อ/ย้อนกลับ44px ความกว้าง330pxเท่ากัน
- gap4–8px และระยะระหว่างปุ่ม8px ข้อความท้าย14px
- การ์ดไม่จำกัดความสูงและไม่เลื่อนภายใน ไม่ใช้scale transformหรือซ่อนscrollbarทั่วเว็บ
- mainใช้box-sizing:border-box ความกว้าง100% เผื่อheaderและsafe-area
- ที่สูงต่ำกว่า600pxหรือกว้างไม่เกิน600px ให้เลื่อนในmainชั้นเดียว การ์ดไม่ถูกตัด
- คงbg-gate.webp โลโก้ ไอคอนแข่งขัน สี ธีม แอนิเมชัน และevent handlerเดิมทั้งหมด

## การทำงาน
- ก้าวเข้าสู่สำนัก: คลิกแล้วไป/academy จริง
- เข้าสู่หอประลองเซียน: คลิกแล้วไป/arena จริง ไม่ได้เริ่มแข่งขันหรือเปลี่ยนคะแนน
- เปลี่ยนชื่อ: เปิดdialogเห็นค่าเดิม แล้วยกเลิก ไม่มีการบันทึกชื่อ
- ย้อนกลับ: เปิดคำชี้แจงและกดดำเนินต่อกลับWelcomeได้
- กดTabจากปุ่มแรกไปปุ่มแข่งขันได้ โฟกัสและoutlineอยู่ในจอ
- ไม่ได้เปลี่ยนค่าเสียง/เต็มจอ และไม่ได้ตรวจแข่งขันหลังเข้าหน้าหอประลอง
