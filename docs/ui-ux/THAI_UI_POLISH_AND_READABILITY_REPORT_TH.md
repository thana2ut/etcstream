# รายงานปรับปรุง UI ภาษาไทยและความอ่านง่าย

วันที่: 2026-10-20 · ยังไม่ได้ commit

## 1. คอมโพเนนต์กลางที่ปรับ

| ไฟล์ | สิ่งที่เปลี่ยน |
|---|---|
| `components/ui/cable-lobby.tsx` | กู้หน้าเลือกสายเป็นแบบเดิม: 3 คอลัมน์ (หมวด / การ์ดสาย / รายละเอียด+กระเป๋า), กระเป๋าแถวละ 5 ช่อง ความสูงช่องปรับให้พอดีพื้นที่อัตโนมัติ, เอาแถบสรุปภารกิจที่เพิ่มทีหลังออก และนำบรรทัดเป้าหมายกลับไปไว้ที่ส่วนหัวตามเดิม ส่วนการจำกัดจำนวนตามสต็อกในด่านยังทำงานเหมือนเดิม |
| `app/cable-lobby.css` | ลบชุดสไตล์ `.cl-unified` ที่จัดหน้าใหม่ออก เพิ่มเพียงให้ชื่อหมวดภาษาไทยขึ้นบรรทัดใหม่ได้แทนการถูกตัด และจัดระยะบรรทัดหมายเหตุ "มีในด่าน … เส้น" |
| `app/xianxia-theme.css` | ป้ายคำสั่งโต้ตอบ: ป้ายปุ่มกว้างตามข้อความ (เช่น "E ค้าง" ไม่ล้นกรอบ 22px อีกต่อไป), ความสูงขั้นต่ำ 44px, ระยะบรรทัด 1.45 สำหรับสระ/วรรณยุกต์ไทย, จำกัดความกว้างและตัดคำได้ |
| `components/game/equipment/generic-device.tsx` | ป้ายชื่ออุปกรณ์และข้อความบนจอ |
| `components/game/operator-console.tsx` | ผังห้องมองจากด้านบน (session อื่นปรับต่อจากรอบนี้ ผมคงโค้ดของ session นั้นไว้) |

## 2. การแก้เฉพาะห้อง
ไม่มี ทุกจุดแก้ที่คอมโพเนนต์กลาง จึงมีผลกับทั้ง 5 สถานที่และห้องฝึกอิสระพร้อมกัน

## 3. คำสั่งโต้ตอบ
ป้าย `E ค้าง 2 วิ · ดูรายละเอียดอุปกรณ์` เดิมเป็นกล่องปุ่มกว้างตายตัว 22px ข้อความ "E ค้าง" จึงล้นกรอบ ตอนนี้ป้ายปุ่มกว้างตามข้อความ (`min-width: 30px`) จัดกึ่งกลางแนวตั้งในกล่องสูง 44px และเว้นระยะซ้ายขวาให้เท่ากัน

## 4. ป้ายชื่ออุปกรณ์
- ชื่ออุปกรณ์ 0.052 และบรรทัดรอง 0.034 (เดิม 0.028) ขอบตัวอักษรหนาขึ้น และเว้นช่องระหว่างสองบรรทัด
- ปรับถ้อยคำ: "รุ่นรอยืนยัน" → "รุ่นรอการยืนยัน", "รุ่นไม่ทราบ" → "ยังไม่ทราบรุ่น", "แบบฝึก" → "อุปกรณ์แบบฝึก"
- กำหนดความกว้างสูงสุดของป้าย ชื่อยาวจึงตัดบรรทัดแทนการยื่นออกไปทับจุดพอร์ต

## 5. ข้อความบนจอ
จอแสดงผลและจอโน้ตบุ๊กใช้ตัวอักษรใหญ่ขึ้นประมาณ 15–25% ระยะบรรทัด 1.35 จัดกึ่งกลางทั้งสองแกน และเพิ่มขอบตัวอักษรบางๆ ให้ตัดกับพื้นจอสีน้ำเงิน

## 6. ผังห้อง
จุดอุปกรณ์ใหญ่ขึ้น สถานะแยกกันชัด: ติดตั้งแล้ว = จุดทึบสีทอง, ยังอยู่ในกล่อง = วงกลมกลวง ชื่อมีขอบตัดพื้นหลัง เลื่อนป้ายหลบเมื่อซ้อนกัน คำอธิบายสัญลักษณ์อ่านง่ายขึ้น และชี้ที่จุดเพื่อดูชื่อเต็มได้ ภายหลัง session อื่นได้ปรับส่วนนี้เพิ่มอีก (ใส่แถบเลื่อนและวางป้ายแบบตาราง)

## 7. ความอ่านง่ายของภาษาไทยโดยรวม
ใช้ระยะบรรทัด 1.3–1.5 กับข้อความไทยทุกจุดที่แก้ เลิกตัดข้อความด้วย `nowrap` ที่ชื่อหมวด เพิ่มขนาดหมายเหตุตรวจรายการจาก .68rem เป็น .76rem และทำให้ข้อความเข้มขึ้น

## 8. สิ่งที่ตรวจแล้ว (เบราว์เซอร์ในแอป ที่ 1440×860)
หน้าเลือกสายระดับ 1 ของทั้ง 5 สถานที่ วัดจาก DOM ได้ผลตรงกันทุกห้อง: คอลัมน์ `236px 724px 400px`, กระเป๋าแถวละ 5 ช่อง, ไม่มีแถบสรุปภารกิจ, ไม่มีการเลื่อนแนวนอน, ไม่มีข้อความถูกตัด
- ห้องเรียน `gate-of-first-light` · สตูดิโอ `moonbridge-of-echoes` · หอประชุม `mirror-tower-of-switching` · กลางแจ้ง `archive-of-ancient-ports` · สนามกีฬา `throne-of-the-grand-transmission`
- เข้าห้องสนามกีฬา SP-01 แล้ว: ห้องเรนเดอร์ได้ ป้ายคำแนะนำสูง 44px ไม่ล้นกรอบ

ข้อจำกัดของการตรวจ: Claude in Chrome เชื่อมต่อไม่ได้ จึงใช้เบราว์เซอร์ในแอปแทน · ใช้โปรไฟล์ทดสอบในเครื่อง โดยตั้งค่าภารกิจที่เลือกใน localStorage เพื่อเปิดแต่ละสถานที่ ไม่ได้ใช้รหัสผู้ดูแล · ห้องฝึกอิสระใช้คอมโพเนนต์ชุดเดียวกัน แต่ยังไม่ได้เปิดดูในเบราว์เซอร์

## 9. แก้เสร็จแล้ว
ดีไซน์หน้าเลือกสายเดิม, ป้าย "E ค้าง" ล้นกรอบ, ป้ายชื่ออุปกรณ์บรรทัดรองเล็กเกินไป, ชื่อหมวดถูกตัด

## 10. ยังต้องปรับต่อ
- โหมดสัมผัสที่จอแคบ (~670px): ปุ่ม 1/2/ใช้งาน/วาง/หมุน ทับปุ่ม "คอนโซล (C)" และ "กระเป๋า"
- ยังไม่ได้ทดลองเล่นจริงเพื่อดูป้ายบนอุปกรณ์ ข้อความบนจอ และผังห้องในทุกห้อง
- `npm test` มีเทสต์ระบบจำลองล้มเหลวหลายข้อ (XS/ST/OUT/SP, stock) ข้อที่ล้มอยู่ในตรรกะการจำลองจากงานที่ยังไม่ commit ไม่ใช่ไฟล์ UI ที่รอบนี้แก้ · `tsc --noEmit` ผ่าน
