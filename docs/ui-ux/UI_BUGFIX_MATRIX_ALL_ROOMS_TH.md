# ตารางปัญหา UI ทุกห้อง

| สถานที่ / ห้อง / หน้าจอ | ประเภทปัญหา | สถานะ | หมายเหตุ |
|---|---|---|---|
| ทุกสถานที่ · หน้าเลือกสาย | ดีไซน์ถูกเปลี่ยน (แถบสรุปภารกิจ, กระเป๋าแถวละ 3 ช่อง) | แก้แล้ว | กู้เป็นแบบ 3 คอลัมน์ กระเป๋าแถวละ 5 ช่อง ตรวจจาก DOM ครบ 5 สถานที่ |
| ทุกสถานที่ · หน้าเลือกสาย | ชื่อหมวดภาษาไทยถูกตัด | แก้แล้ว | ขึ้นบรรทัดใหม่ได้ |
| ทุกห้อง · ป้ายคำสั่ง | "E ค้าง" ล้นกรอบปุ่ม 22px | แก้แล้ว (ตรวจจากโค้ด/CSS) | ยังไม่เห็นป้ายแบบค้างกดบนหน้าจอจริง |
| ทุกห้อง · ป้ายคำแนะนำ | ความสูงและระยะบรรทัด | แก้แล้ว | วัดได้ 44px ที่ SP-01 |
| ทุกห้อง · ป้ายชื่ออุปกรณ์ | บรรทัดรองเล็กเกินไปและถ้อยคำไม่เป็นธรรมชาติ | แก้บางส่วน | ยังต้องดูในเกมจริง |
| ทุกห้อง · ข้อความบนจอ | ตัวอักษรเล็กและจางเกินไป | แก้บางส่วน | ยังต้องดูในเกมจริง |
| ทุกห้อง · ผังห้อง (คอนโซล C) | ป้ายเล็กและซ้อนกัน คำอธิบายสัญลักษณ์อ่านยาก | แก้แล้ว | session อื่นปรับต่อในภายหลัง |
| ทุกห้อง · โหมดสัมผัส จอแคบ | ปุ่มสัมผัสทับปุ่มคอนโซลและกระเป๋า | ต้องตามแก้ | พบที่ SP-01 กว้าง ~670px |
| ห้องฝึกอิสระ | คอมโพเนนต์ชุดเดียวกัน | แก้บางส่วน | ยังไม่ได้เปิดดูในเบราว์เซอร์ |
