## 2. รูปแบบเดิมที่คืนมา
- **แท็บคำชี้แจง:**
  - ตราสำนักกลางหน้า หัวข้อ `คำชี้แจงแห่งสำนัก` และเส้นคั่นทอง
  - บรรทัดต้อนรับ `ยินดีต้อนรับสู่ etcstream · ผู้ฝึก <ชื่อจริงของผู้เล่น>` ถ้ายังไม่ได้จารึกชื่อจะแสดงแค่คำต้อนรับ ไม่มีชื่อตัวอย่าง
  - ย่อหน้าอ่านต่อเนื่อง 3 ย่อหน้า และกล่องข้อความเตือนใจท้ายหน้า 1 กล่อง
- **แท็บอื่น:**
  - ใช้รูปแบบย่อหน้าเดียวกัน
  - แท็บวิธีเล่นมีแถบขั้นตอน (อ่านใบงาน → เตรียมสาย → เข้าห้อง → เชื่อมต่อ → ทดสอบระบบ) เหมือนแบบเดิม
  - แท็บกฎสำนักกลับมาใช้กล่องคำคมแบบเดิม
- ไม่มีการ์ดซ้อนหรือรายการจุดในเนื้อหาหลักแล้ว

## 3. เนื้อหาปัจจุบันที่ยังอยู่ครบ (เรียบเรียงเป็นย่อหน้า)
- **คำชี้แจง:**
  - etcstream คืออะไรและจะได้เรียนรู้อะไร
  - โหมดภารกิจ (5 สถานที่ × 5 ระดับ) กับห้องฝึกอิสระ (ไม่มีด่านบังคับ)
  - เส้นทางการฝึก และควรเริ่มที่ไหน
- **บริบท:**
  - "ปราณสัญญาณ" กับงานโสตทัศน์จริง และตัวอย่างเส้นทางภาพและเสียง
  - ห้าสถานที่ที่ยากขึ้น (คำใบ้น้อยลงในระดับสูง)
  - อุปกรณ์จำลองที่รุ่นยังรอยืนยัน
- **วิธีเล่น:**
  - ลำดับภารกิจ: บรีฟ → เตรียมสาย → ระบบตรวจกระเป๋า ห้องฝึกอิสระเลือกสายจากโต๊ะสาย
  - ปุ่มคอมพิวเตอร์ครบ (`WASD`, เมาส์, `E`, `F`, `T`, `E` ค้าง 2 วินาที, `1`/`2`+`E`, `R`, `C`) และปุ่มจอสัมผัส
  - การเล่นต่อจากครั้งล่าสุด
- **กฎสำนัก:**
  - ต่อถูกทิศ (OUTPUT→INPUT) และหัวสายตรงชนิดพอร์ต
  - การนับความผิดและการพักทบทวน (หยิบแล้ววางคืนไม่นับ)
  - กระเป๋าต้องครบและไม่เกิน โดยระบบไม่เฉลยคำตอบ
  - ผ่านเมื่อทดสอบผ่าน แก้สายหลังทดสอบต้องทดสอบใหม่ และงานกลางแจ้งต้องประเมินความปลอดภัยก่อนเริ่ม
- **บทบาท:** ผู้ฝึกปราณแห่งสายสัญญาณ, สิ่งที่ต้องดูแล (ต้นทาง / ประมวลผล / ปลายทาง), การสะสมคุณความดีและเลื่อนขั้น

ไม่มีรายการสายหรือคำตอบของด่าน และไม่ได้กล่าวถึงระบบที่เลิกใช้แล้ว ส่วนการเข้าด่านแบบผู้ดูแลไม่ได้ใส่ไว้ในคู่มือผู้เล่น เพราะเป็นเครื่องมือทดสอบ

## 4. แท็บและปุ่มที่คงไว้
- **แท็บ:** ห้าแท็บเดิมตามลำดับเดิม (`คำชี้แจง` / `บริบท` / `วิธีเล่น` / `กฎสำนัก` / `บทบาท`)
- **ปุ่มและตัวเลือก:**
  - `ย้อนกลับ` เรียก `onBack`
  - `ไม่แสดงอีกในครั้งถัดไป` บันทึก `streamlab_skip_intro`
  - `ปิดจารึกและดำเนินต่อ` เรียก `onClose`
- **หน้าต่างและการเลื่อน:**
  - ภาพอาจารย์สองท่าน กรอบทอง และพื้นหลังเหมือนเดิม
  - เนื้อหายาวเลื่อนในกล่องเดียว (`.modal-content-scroll`)
  - การหยุดแอนิเมชันพื้นหลังขณะเปิดหน้าต่างยังทำงานตามเดิม
- **ที่ไม่ได้คืนกลับมา:**
  - ปุ่ม X มุมขวาบน (ไม่มี `modal-close-x` ในไฟล์นี้แล้ว)
  - ลวดลายมุมซ้ายบนของกรอบหน้าบรีฟภารกิจ ซึ่งลบไว้ก่อนหน้า ส่วนนี้อยู่ในไฟล์อื่น รอบนี้ไม่ได้แตะ
