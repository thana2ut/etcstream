## ไฟล์ที่เปลี่ยน
- `app/page.tsx`
- `app/xianxia-theme.css` (สไตล์ `.welcome-rename-*` และ `.welcome-name-row`)

## เปลี่ยนชื่อ
- **ปุ่ม:** รูปดินสอวงกลม 36 px ข้างชื่อผู้ฝึก มี `aria-label` / `title` = `เปลี่ยนชื่อผู้ฝึก` และกรอบโฟกัสสีฟ้าเมื่อใช้คีย์บอร์ด
- **กล่องเปลี่ยนชื่อ:** หัวข้อ `เปลี่ยนชื่อผู้ฝึก` เติมชื่อเดิมไว้ให้ มีปุ่ม `บันทึก` / `ยกเลิก` ปิดได้ด้วย Esc หรือคลิกพื้นหลัง
- **การบันทึก:** ใช้ `validateNickname` และ `setPlayer` ของ `useAcademyStore` ชุดเดียวกับหน้าจารึกชื่อ ไม่สร้างที่เก็บข้อมูลใหม่ โปรไฟล์เดิม (playerId และความคืบหน้า) ยังอยู่ครบ เปลี่ยนเฉพาะ `nickname` และ `lastPlayedAt` ชื่อบนหน้าอื่นอ่านจาก store เดียวกันจึงอัปเดตตาม
- **ชื่อไม่ถูกต้อง:** ชื่อว่างหรือผิดเงื่อนไข (2–20 ตัวอักษร ไทย อังกฤษ ตัวเลข เว้นวรรค) แสดง `copy.name.invalid` ถ้าบันทึกไม่สำเร็จแสดง `copy.name.saveError` และคงชื่อเดิมไว้
- **ยกเลิก:** ปิดกล่องโดยไม่เปลี่ยนชื่อ

## ปุ่มย้อนกลับ
- **ไปที่:** หน้าคำอธิบาย (`InstructionsModal`) ซึ่งอยู่ก่อนหน้าจารึกชื่อและหน้าต้อนรับในลำดับเดิม
- **วิธีทำ:** ตั้ง phase เป็น `landing` แล้วเปิด modal ไม่ใช้ประวัติของเบราว์เซอร์
- **กดดำเนินการต่อจากหน้าคำอธิบาย:** `proceedToNameOrWelcome` พากลับหน้าต้อนรับ เพราะมีผู้ฝึกอยู่แล้วและ `changeName = false`
- **กดย้อนกลับในหน้าคำอธิบาย:** ไปหน้าแรกตามพฤติกรรมเดิม
- ไม่ลบชื่อ ไม่รีเซ็ตความคืบหน้า

## สิ่งที่เจ้าของโครงการควรตรวจ
- ไอคอนอยู่กึ่งกลางกับชื่อยาว/สั้น และไม่ทับสระหรือวรรณยุกต์
- บันทึก/ยกเลิก/ชื่อว่าง ทำงานตามที่ระบุ
- ย้อนกลับไปหน้าคำอธิบาย แล้วไปต่อกลับมาหน้าต้อนรับได้

## อัปเดต: ย้ายปุ่มเปลี่ยนชื่อ
เอาไอคอนดินสอข้างชื่อออกแล้ว ตอนนี้ใช้ปุ่มเต็ม `เปลี่ยนชื่อ` แบบกรอบเดียวกับ `ย้อนกลับ` (`cultivation-back-btn welcome-back-btn`) วางอยู่ใต้ `ก้าวเข้าสู่สำนัก` และอยู่เหนือ `ย้อนกลับ` ปุ่มนี้เปิดกล่องเปลี่ยนชื่อชุดเดิม
