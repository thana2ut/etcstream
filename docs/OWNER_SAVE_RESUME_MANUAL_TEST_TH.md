# คู่มือทดสอบการบันทึกและเล่นต่อ (สำหรับเจ้าของโครงการ)

**เตรียมก่อนทดสอบ:** เปิด DevTools → Application → Local Storage แล้วดู key `etcstream-run-v1:*` ประกอบได้

**ข้อมูลที่ควรเก็บเมื่อพบบั๊ก:**
- รหัสด่าน
- ขั้นตอนที่ทำ
- ภาพหน้าจอก่อนและหลังเข้าใหม่
- ค่าของ key `etcstream-run-v1:...` (คัดลอกข้อความ JSON)
- ข้อความ error ใน Console

- [ ] **1. ST-02 ย้ายโน้ตบุ๊ก**
  - ทำ: เข้า ST-02 → ย้ายโน้ตบุ๊กไปวางบนโต๊ะกลม → รอเห็น "บันทึกล่าสุดแล้ว" → ออกจากห้องฝึก → ไปสำนัก → กลับมาเลือก ST-02
  - ผลที่คาด: เห็นหน้าต่าง "พบการฝึกที่ยังดำเนินอยู่" → กด "เล่นต่อจากครั้งล่าสุด" → โน้ตบุ๊กยังอยู่บนโต๊ะกลม และไม่ต้องผ่านหน้าเตรียมสาย
- [ ] **2. สายสองเส้นในกระเป๋า**
  - ทำ: ใส่สาย 2 เส้นไว้ในกระเป๋า (ยังไม่หยิบออก) → ออก → เข้าใหม่ → เล่นต่อ
  - ผลที่คาด: กระเป๋า (R) มีสายเส้นเดิม 2 เส้น ไม่เพิ่ม ไม่หาย
- [ ] **3. ต่อสายครึ่งเดียว**
  - ทำ: เสียบปลายด้านเดียวของสาย อีกด้านวางไว้ → ออก → เข้าใหม่
  - ผลที่คาด: ปลายที่เสียบยังเสียบพอร์ตเดิม อีกปลายอยู่ตำแหน่งเดิม
- [ ] **4. ต่อครบและปรับเครื่อง**
  - ทำ: ต่อสายครบหนึ่งเส้น → เปิดคอนโซล (C) → ปรับมิกเซอร์ / สวิตเชอร์ / ปิด-เปิดเครื่อง → ออก → เข้าใหม่
  - ผลที่คาด: ค่าการตั้งค่าในคอนโซลตรงกับเดิม และสัญญาณบนจอ/แผนผังคำนวณตามสถานะนั้น
- [ ] **5. ย้ายอุปกรณ์อื่น**
  - ทำ: ย้ายอุปกรณ์พกพาอีกชิ้นไปวางที่จุดใช้งาน → รีเฟรชหน้า (F5) → เล่นต่อ
  - ผลที่คาด: อุปกรณ์อยู่ตำแหน่งเดิม ไม่ซ้ำ ไม่จมโต๊ะ
- [ ] **6. ออกกลางภารกิจ**
  - ทำ: ทำภารกิจไปครึ่งหนึ่ง → ออก → เล่นต่อ
  - ผลที่คาด: ตัวนับความคืบหน้า (X/Y ขั้น) ตรงกับสายและอุปกรณ์ที่ต่อจริงในห้อง
- [ ] **7. ทำให้ระบบเสียหลังทดสอบ**
  - ทำ: ผ่านการทดสอบแล้วถอดสายสำคัญหนึ่งเส้น → ออก → เข้าใหม่
  - ผลที่คาด: ยังส่งงานไม่ได้จนกว่าจะต่อใหม่และทดสอบซ้ำ
- [ ] **8. เริ่มใหม่**
  - ทำ: ที่หน้าต่างเล่นต่อ กด "เริ่มใหม่" → จะมีหน้ายืนยัน → กด "ยืนยัน เริ่มใหม่"
  - ผลที่คาด: เข้าสู่บรีฟ → เตรียมสาย → ห้องค่าเริ่มต้น ด่านที่ผ่านแล้วและการปลดล็อกยังอยู่
- [ ] **9. สลับด่าน**
  - ทำ: ทำงานค้างใน ST-02 → ออก → เข้าด่านอื่นและทำงานค้าง → กลับมา ST-02
  - ผลที่คาด: ทั้งสองด่านมีบันทึกของตัวเอง ไม่ทับกัน (ดู key ที่ลงท้าย `s-2` และของอีกด่าน)
- [ ] **10. ห้องฝึกอิสระ**
  - ทำ: ย้ายหรือต่ออุปกรณ์ → กลับสำนัก → เปิดห้องฝึกอิสระอีกครั้ง
  - ผลที่คาด: เห็นหน้าต่างเล่นต่อของ "ห้องฝึกอิสระ" (key `:free-practice:studio-full`) แยกจากภารกิจ
- [ ] **11. รีเฟรช / ปิด-เปิดเบราว์เซอร์**
  - ทำ: รีเฟรชหน้าระหว่างเล่น แล้วลองปิดเบราว์เซอร์และเปิดใหม่ → เลือกด่านเดิม
  - ผลที่คาด: มีตัวเลือก "เล่นต่อจากครั้งล่าสุด"
- [ ] **12. บันทึกเสียหายหรือเขียนไม่ได้**
  - ทำ: แก้ JSON ของ key ให้ผิด (เช่น ลบปีกกาออก) → เข้าด่าน
  - ผลที่คาด: เห็น "พบบันทึกการฝึกที่ต้องตรวจสอบ" พร้อมเหตุผลภาษาไทย ไม่มีปุ่มเล่นต่อ และบันทึกเดิมยังอยู่จนกว่าจะเลือกเริ่มใหม่
  - (ถ้าทดสอบได้) เต็มพื้นที่ storage → สถานะต้องขึ้น "บันทึกไม่สำเร็จ โปรดลองอีกครั้ง" และไม่ขึ้น "บันทึกล่าสุดแล้ว"
- [ ] **13. เข้าผ่านหน้าผู้ดูแล**
  - ทำ: เข้าด่านเดียวกันผ่านหน้าผู้ดูแล
  - ผลที่คาด: บันทึกใช้ key `:mission-admin:` แยกจากบันทึกของผู้เล่น (`:mission:`)
- [ ] **14. iPhone Safari**
  - ทำ: เล่น → สลับไปแอปอื่นหรือหน้าจอหลัก → กลับมา หรือปิดแท็บ → เข้าใหม่
  - ผลที่คาด: การเปลี่ยนแปลงล่าสุดถูกบันทึก (ระบบบันทึกทุกครั้งที่มีการกระทำ และตอนแท็บถูกซ่อน)

**หมายเหตุ:**
- กลับเข้าห้องแล้วตัวละครจะเกิดที่จุดเริ่มต้นของห้องเสมอ ระบบไม่ได้บันทึกตำแหน่งผู้เล่น
- บันทึกอยู่เฉพาะในเบราว์เซอร์และโปรไฟล์ที่ใช้เล่น ไม่ซิงก์ข้ามเครื่อง
