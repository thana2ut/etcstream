# ปรับตำแหน่งและการเคลื่อนไหวของมือมุมมองบุคคลที่หนึ่ง

วันที่: 2026-10-20 · ยังไม่ได้ commit · ยังไม่ได้ทดสอบในเกม

## 1. ระบบกลางที่ปรับ
- `components/game/first-person-hands.tsx`: ภาพมือแบบ 2D overlay ใช้ร่วมกันทุกห้อง รวมห้องฝึกอิสระ
- `app/xianxia-theme.css`: กลุ่ม `.fp-hands` / `.fp-hand`

## 2. ตำแหน่งมือ
ระยะห่างจากกึ่งกลางจอถึงขอบในของมือเปลี่ยนจาก `max(250px, 15vw)` เป็น `max(236px, 13.5vw)` ผ่านตัวแปรกลาง `--fp-hand-gap` ที่ประกาศใน `:root` มือทั้งสองข้างจึงเข้าใกล้กันขึ้นเล็กน้อย:
- ที่จอ 1920 px เข้ามาข้างละประมาณ 29 px
- ที่จอเล็กเข้ามาข้างละ 14 px

มุมเอียงลดจาก 26° เป็น 25° และจุดหมุนย้ายไปที่ข้อมือ (`50% 85%`) ท่าทางจึงดูมั่นคงขึ้น

## 3. การกันไม่ให้บังข้อความ
ป้ายคำสั่งกลางจอคำนวณความกว้างสูงสุดจากตัวแปร `--fp-hand-gap` ตัวเดียวกัน (`2 × gap − 16px`) ป้ายจึงอยู่ในช่องว่างระหว่างมือเสมอ ส่วนแผงภารกิจและแผงอื่นอยู่ชั้นสูงกว่ามือ (`z-index`) เหมือนเดิม

## 4. การเคลื่อนไหว
- **หายใจ:** ขึ้นลงช้า 4.6 วินาที
- **ข้อมือส่าย:** ±0.7° รอบ 7.3 วินาที ทั้งสองมือต่างจังหวะกัน ภาพจึงไม่ดูนิ่ง
- **ตามเมาส์:** มือหน่วงตามการหันกล้องแล้วดีดกลับ (ระบบเดิม)
- **เดิน:** กด WASD หรือลูกศรแล้วมือแกว่งเป็นรูปเลขแปดเบาๆ (±4 px แนวนอน, 5 px แนวตั้ง) ค่อยๆ เริ่มและค่อยๆ หยุด มือซ้ายและขวาแกว่งสวนทางกัน และจะหยุดทันทีเมื่อหน้าต่างเสียโฟกัส
- **ผู้ที่ตั้งค่าลดการเคลื่อนไหว (`prefers-reduced-motion`):** ไม่มีแอนิเมชันเหมือนเดิม

## 5. ห้องที่ครอบคลุม
ทุกห้องและห้องฝึกอิสระใช้คอมโพเนนต์เดียวกัน ยังไม่ได้ตรวจด้วยตา

## 6. จุดที่อาจต้องปรับต่อ
- จอแนวตั้ง (`max-aspect-ratio: 1/1`) ใช้ขนาดมือ 40vw ควรดูว่ามือบังป้ายหรือไม่
- โหมดสัมผัสซ่อนมือบนจอแคบตามเดิม
