# รายงานส่งมอบ V3 สำหรับเจ้าของ

20 ตุลาคม 2026

เพิ่มปุ่ม “เข้าสู่หอประลองเซียน” ใต้ปุ่มหลักเดิม ใช้ภาพจริงจากแพ็ก 16 ไฟล์ ตรวจเทียบต้นฉบับตรงทุกไบต์ และตรวจภาพเดิมใน public/images 19 ไฟล์ไม่เปลี่ยน ไม่ใช้ภาพ Welcome ทางเลือก

เพิ่มหน้า /arena พร้อมจับเวลาจากด่านจริง 25 ระดับ สหาย ข้อมูลส่วนตัว รายชื่อที่ยินยอมเปิดเผย และทำเนียบที่รับเฉพาะผลยืนยันจริง ใช้ฐานข้อมูล SQLite ฝั่งเซิร์ฟเวอร์เดียว ไม่อ่านรายชื่อผู้เล่นอื่นหรือคะแนนจาก localStorage มีตัวตนสุ่ม คุกกี้ HttpOnly รหัสสหาย และสถานะออนไลน์ที่ต้องยินยอม/หมดอายุ 90 วินาที

รวมประตูผู้ดูแลไว้ /admin และ /admin/missions ใช้เซสชันฝั่งเซิร์ฟเวอร์เดียวกัน /missions/admin เหลือการเปลี่ยนทางที่ตรวจสิทธิ์ ไม่มีแบบฟอร์มรหัสเดิมหรือ sessionStorage ที่ให้อำนาจผู้ดูแล มีการเปลี่ยน/ล้างชื่อ ซ่อน ระงับ คืนสิทธิ์ และทำให้ไม่ระบุตัวตนแบบยืนยันรหัสเป้าหมายพร้อมเหตุผล การล้างชื่อไม่ลบประวัติ และชื่อเก่าในเครื่องเขียนทับกลับไม่ได้ มีประวัติการดำเนินการและการยกเลิกผล/กติกาแบบเวอร์ชัน

## ยังไม่ครบและไม่ควรอ้างว่าเปิดแข่งขันจริงแล้ว

- ฐานข้อมูลจริงและบัญชีผู้ดูแลยังไม่ได้ตั้งค่า ต้องให้เจ้าของตรวจ server/arena/schema.sql แล้วรัน scripts/provision-arena.mjs ด้วยตนเองตามข้อกำหนดห้ามรัน migration และข้อกำหนดให้เจ้าของกรอกรหัสผ่านใน prompt ที่ซ่อนตัวอักษร ไม่ส่งรหัสในแชต ไม่ใส่รหัสในคำสั่ง
- Time Attack มีเวลาและผลฝั่งเซิร์ฟเวอร์ แต่ทุกผลยัง “รอตรวจ ไม่จัดอันดับ” การตรวจกราฟจากข้อมูลเบราว์เซอร์ไม่ใช่ระบบตรวจย้อนกลับคำสั่งครบทั้งรอบ จึงยังไม่มีทางยืนยันผลเป็นอันดับด้วยปุ่มลัด
- 1v1 ปิดไว้จริง ไม่สร้างคู่แข่ง/ห้อง/ผู้ชนะสมมติ ต้องเพิ่มการตรวจคำสั่ง การเริ่มพร้อมกัน การหลุดเชื่อมต่อ และทดสอบหลายเครื่องก่อน
- ยังไม่ตรวจ Chrome ภาพหน้าจอหลายขนาด การเดินเล่น การคืนสถานะห้องเดิม และการเห็นผู้เล่นจริงจากสองเบราว์เซอร์
- บริการออนไลน์แบบโฮสต์และฐานข้อมูลหลายเครื่องยังไม่ได้ติดตั้ง SQLite ปัจจุบันเหมาะกับหลายเบราว์เซอร์ที่เชื่อมเซิร์ฟเวอร์เดียวและไฟล์ถาวรเดียว ต้องมี HTTPS/เครือข่าย/พื้นที่เก็บข้อมูลและการสำรองที่เจ้าของจัดให้

## วิธีเริ่มหลังตรวจไฟล์

เปิด PowerShell และตรวจว่าอยู่ใน D:\etcstream ก่อนรันคำสั่ง:

```powershell
node scripts/provision-arena.mjs
```

กรอกรหัสตั้งต้นเดิมในหน้าถามแบบซ่อน ยืนยัน จากนั้นเปิด /admin และบังคับเปลี่ยนเป็นรหัสใหม่ที่แข็งแรงก่อนเปิดส่วนผู้ดูแล หากยังไม่มีเซิร์ฟเวอร์ทำงานจึงใช้ npm run dev ของโครงการเดิม ห้ามเปิดซ้ำบนพอร์ต 3000

ผลตรวจ: lint ผ่าน, build/TypeScript ผ่าน, ชุดทดสอบที่เลือกผ่าน 25/25, git diff --check ผ่าน ชุดทดสอบใช้เฉพาะฐานข้อมูลชั่วคราวนอกโปรเจกต์และลบทิ้ง ไม่ได้สร้างผู้เล่นทดสอบในฐานจริง ไม่ได้ commit/push หรือแก้ .env.local
