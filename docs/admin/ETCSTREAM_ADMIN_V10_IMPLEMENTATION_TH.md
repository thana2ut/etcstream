## สาเหตุและสิ่งที่แก้

วิดีโอ `Screen Recording 2026-10-20 152801.mp4` ยาวประมาณ 5.23 วินาทีแสดงหัวข้อใหญ่หลายชั้นก่อนการ์ด 3+2 แถว และต้องเลื่อนเพื่อเห็นบท 04/05 โค้ดเดิมมีหัวตำหนัก แถบนำทาง หัวข้อห้อง หัวหอภารกิจ และการ์ดขั้นต่ำ 360px พร้อมพื้นที่ภาพ 145px และคำอธิบายเต็ม จึงสูงเกินหน้าจอ

แก้เฉพาะแอดมิน: ใช้แถบคำสั่งสั้น พร้อมสถานะผู้ดูแล กลับสามห้อง ออกจากระบบ และออกกลับสำนัก ตัดหัวข้อซ้ำ จัดภาพทั้งห้าจากไฟล์เดิมเป็นพื้นที่ภาพสัดส่วนเดียวกัน ความสูงปรับตาม `dvh` ใช้ชื่อบทและสถานที่จริง คำบรรยายสั้น และท้ายการ์ดตรงกัน รูปแบบเดสก์ท็อปยังเป็น 01/02/03 และ 04/05 กึ่งกลาง หน้าต่างแคบหรือเตี้ยเปลี่ยนสอง/หนึ่งคอลัมน์และเลื่อนตามธรรมชาติ ไม่มีการซ่อน overflow ของหน้าเพื่อบังเนื้อหา รายละเอียดหลังเลือกบทยังคงแสดงห้าระดับและเนื้อหาเดิม

เป้าหมายองค์ประกอบคือ 1366×768, 1536×864, 1600×900, 1920×1080 และสัดส่วนวิดีโอเจ้าของ ยังไม่ได้เปิดเว็บวัดผลจริงตามคำสั่ง จึงต้องให้เจ้าของยืนยันเรื่องฟอนต์ การตัดภาพ และการพอดีจอด้วยตนเอง

## สิทธิ์ประตูเดียว

เอาฟอร์มและคำเตือนรหัสแข่งขันแยกออก รวมถึงสถานะ `competition` และการอ่านไฟล์รหัสแยกจากระบบที่ใช้งาน ทุกคำขอข้อมูลและการแก้ไขแข่งขันใน `/api/admin/*` ยังผ่าน `requireSession("admin")` และ `adminEntry` ก่อนเข้าถึงข้อมูล: ตรวจคุกกี้ฝั่งเซิร์ฟเวอร์ เซสชันฐานข้อมูล อายุ สิทธิ์ผู้ดูแลที่ยังใช้งาน และข้อกำหนดเปลี่ยนรหัสตั้งต้น ไม่มีการเชื่อสถานะ React หรือ localStorage เป็นสิทธิ์จริง

`competition-status/unlock/lock` เดิมคงไว้เพื่อความเข้ากันได้ แต่ทั้งหมดอยู่หลังประตูหลัก ไม่ตรวจรหัสที่สอง และการสลับห้องไม่เรียกล็อกสิทธิ์แยกอีก การออกจากระบบยังลบเซสชันและสิทธิ์ประตูหลักพร้อมกัน หน้าผู้ดูแลยังปิดข้อมูลเมื่อพบหมดอายุหรือยืนยันเซสชันไม่ได้ ตรวจต้นทางคำขอ คุกกี้ปลอดภัย จำกัดการลองรหัส และประวัติการแก้ไขเดิมยังอยู่ ไม่อ่าน เปลี่ยน หรือลบไฟล์ข้อมูลรับรองส่วนตัวเก่า

หน้าแข่งขันเรียกข้อมูลจริงจาก AdminPanel เดิม หากฐานข้อมูลยังไม่พร้อม จะรายงานข้อผิดพลาดจริง ไม่สร้างข้อมูลสำเร็จจำลอง ไม่มีการแก้ระบบออนไลน์ V9

- `SECURITY.md`, `docs/online-arena/ARENA_ONLINE_DEPLOY_TH.md`: ระบุข้อกำหนดล่าสุดแทนประตูแข่งขันแยก

## สิ่งที่คงเดิมและข้อจำกัด

ไม่แก้ฉาก 3D ระบบสาย/พอร์ต/คะแนน ข้อมูลผู้เล่น ความคืบหน้า อันดับ และหน้าหอภารกิจสาธารณะ ไม่แก้ชุดสายสำหรับโหมดเล่นตรวจ V8 และไม่เชื่อมต่อสายอัตโนมัติ ไม่ติดตั้งแพ็กเกจ ไม่แก้ `.env.local` ไม่รัน SQL/migration/seed และไม่ commit/push/deploy

ข้อจำกัดการติดตั้ง SQLite/เซิร์ฟเวอร์ Node เดียวและสิทธิ์ประตูที่เก็บในหน่วยความจำยังเหมือน V8/V9 ไม่ได้ยืนยันฐานข้อมูลหรือความปลอดภัยขณะรันจริงในงานนี้ ไม่ได้รัน tests/lint/typecheck/build/browser automation หรือเล่นเกมตรวจสอบ

## ต้าตรวจเองหลังนำไปใช้

1. เปิด `/admin` จากภายนอก ใส่รหัสหลักครั้งเดียว แล้วเลือกแข่งขัน ต้องเห็นเครื่องมือจริงโดยไม่มีฟอร์มรหัสเพิ่ม
2. สลับครบสามห้อง ตรวจว่าข้อมูลจริงยังโหลด และข้อผิดพลาดฐานข้อมูลไม่ได้ถูกซ่อน
3. เปิดห้องภารกิจที่ขนาดเป้าหมาย ตรวจการ์ดทั้งห้า 3+2 ครบภาพ ชื่อ และปุ่มในจอเดียว รวมถึงแป้น Tab/จุดโฟกัส
4. เลือกแต่ละบทและระดับ ตรวจเข้าเล่นพร้อมชุดสายถูกต้อง ไม่ผ่านหน้าเลือกสาย และไม่บันทึกความคืบหน้า/อันดับผู้เล่น
5. ย่อหน้าต่าง/ซูมข้อความ/เปิดมือถือ ต้องเลื่อนเข้าถึงทุกส่วนได้โดยไม่ถูกครอบตัด
6. ออกจากระบบ แล้วเข้าจากภายนอกใหม่ ต้องถามรหัสหลักอีก ทดลอง API แอดมินจากเซสชันที่ไม่มีสิทธิ์หรือหมดอายุ ต้องถูกปฏิเสธ ตรวจด้วยว่าผู้เล่นสาธารณะไม่ได้สิทธิ์ดูแล
