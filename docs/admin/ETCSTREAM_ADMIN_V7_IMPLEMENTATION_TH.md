# ส่งมอบตำหนักบัญชาการ V7

สถานะ: **IMPLEMENTED — NOT TESTED — OWNER QA REQUIRED**

งานนี้แก้ซอร์สใน `D:\etcstream` ตามเอกสาร V7 ซึ่งแทนข้อกำหนดเส้นทางผู้ดูแลเดิม ไม่รันเทสต์ ลินต์ บิลด์ ตรวจชนิดข้อมูล เบราว์เซอร์ เกม หรือคำสั่งตรวจฐานข้อมูล ไม่สร้างภาพผลลัพธ์ที่ไม่ได้เปิดดูจริง ไม่ commit/push/deploy และไม่รัน migration/seed หรือแก้ `.env.local`

## หน้าผู้ดูแลและแผนย้าย

เข้า `http://localhost:3000/admin` เท่านั้น รากหน้าตรวจเซสชันฝั่งเซิร์ฟเวอร์ก่อนส่งคอมโพเนนต์ที่มีสิทธิ์ กรณีไม่มีเซสชันหรือยังต้องเปลี่ยนรหัสจะเห็นประตูเข้าสู่ระบบที่ URL เดิม

| ส่วนเดิม | ตำแหน่งใหม่ |
|---|---|
| Overview/Players/Attempts/Leaderboards/Friends/Matches/Settings/Audit/Seasons/Reviews | `/admin` → ห้องแข่งขัน → ปุ่มส่วนงานภายในหน้า |
| ไม่มีหน้าแอดมินสำหรับฝึกอิสระโดยเฉพาะ | `/admin` → ห้องฝึก → 5 ส่วนข้อมูลตามความสามารถจริง |
| `MissionHall admin` เดิม | `/admin` → ห้องภารกิจ → ห้าสถานที่และห้าระดับเดิม |
| `/admin/missions`, `/missions/admin`, `/admin/[section]` เก่า | redirect แบบปลายทางคงที่ไป `/admin` ไม่มี UI หรือ login ที่สอง |
| `/api/admin/...` | คง API เดิมและตัวตรวจเซสชันฝั่งเซิร์ฟเวอร์ |

หน้าเริ่มต้นมีสามการ์ดเท่านั้น เมนูหลักและเมนูรองเปลี่ยน React state ไม่ใช้ router ไปหน้าแอดมินย่อยหรือพารามิเตอร์ให้สิทธิ์ เมนูห้องที่เคยเปิดคงสถานะไว้ในหน้า หอภารกิจโหลดเมื่อเลือกครั้งแรก มีหัวเรื่องเดียวกับภาพพื้นหลังผู้ดูแลเดิม ใช้ปุ่มที่กดด้วยคีย์บอร์ดได้ พร้อม focus และรูปแบบแคบ หน้ายาวเลื่อนได้ตามเนื้อหา ตารางมีพื้นที่เลื่อนแนวนอนเมื่อจำเป็น

## ระบบที่เชื่อมต่อจริง

- ห้องแข่งขันใช้ `AdminPanel`, `SeasonManager`, `ReviewManager` และ API/บริการเดิม ข้อมูลผู้เล่นแยกด้วย ID ถาวร การค้นหา การแบ่งหน้า เปลี่ยนชื่อ ล้างชื่อ ซ่อนข้อมูลสาธารณะ ระงับ/คืนสิทธิ์ ทำข้อมูลนิรนาม ยกเลิก/คืนสถานะผล กติกา ประวัติ ฤดูกาลและคิวตรวจผล คงคำสั่งเดิม
- ไม่มีปุ่มรับรองผลปลอม ไม่มีการแก้เวลาเพื่อสร้างผล VERIFIED หรือคะแนนแรงก์ ผลที่ขาดหลักฐานยังรอตรวจ Duel ยังไม่เปิดตามระบบเดิม
- ห้องฝึกเรียก `GET /api/admin/training` หลัง `requireSession` เท่านั้น อ่าน `SCENARIOS["studio-full"]` จริง แสดงรายการอุปกรณ์ รุ่น สาย พอร์ต เงื่อนไขสัญญาณและเส้นทางที่โค้ดเดิมระบุว่ายังเป็นสมมติฐาน ตัวเลขเป็นจำนวนรายการตั้งค่า ไม่ใช่ผู้ฝึกออนไลน์หรือการรับรองว่าเกมพร้อมจากการทดสอบ
- ประวัติผู้ฝึก กิจกรรมและคำสั่งตั้งค่าฝึกส่วนกลางยังไม่มี จึงแสดงข้อความตรงตามจริง ไม่มีปุ่มจำลอง ไม่มีการอ่านหรือรีเซ็ต localStorage ของผู้อื่น

## หอภารกิจเดิม

ใช้ไฟล์ `components/ui/mission-hall.tsx` เดิม ไม่สร้างชุดภารกิจทดแทน คง `missionChapters.map`, `selectedSlug`, `selectedLevel`, รายละเอียดห้าระดับ, `getDifficultyMeta`, `selectMission` และสัญญาเริ่ม `/play?mode=mission&mission=...&difficulty=...` เดิม คงชุดสาย กราฟและการตรวจการต่อที่มีอยู่

เพิ่มเฉพาะกรอบ embedded/active เพื่อไม่ซ้อนหัวและฉากหลัง และปิดรายละเอียดเมื่อออกจากห้อง การเล่นตรวจภารกิจยังออกไป `/play` ตามเดิม ซึ่งเป็นเส้นทางเกม ไม่ใช่หน้าผู้ดูแลอีกหน้า ปุ่มกลับมาที่ `/admin` ส่วนการดูแลทั้งหมดอยู่ในหน้านี้

โมดูลเดิมต้องมีโปรไฟล์ฝึกในเบราว์เซอร์ เมื่อไม่มีจะแสดงคำแนะนำไปสร้างโปรไฟล์จริงที่หน้าต้อนรับแทนการสร้างผู้เล่นเอง การเลือกและดูรายละเอียดไม่ผ่านด่านให้เอง เพิ่มทางแยกเฉพาะการเล่นตรวจที่มี `selected.admin` ในหน้าเกม เพื่อไม่เรียก `completeMission` หรือมอบบุญ/แรงก์ให้ผู้เล่นจากการตรวจของแอดมิน ส่วนการเล่นผู้เล่นปกติคงทางเดิม

## ความปลอดภัย

ใช้ session cookie, scrypt, rate limit, บังคับเปลี่ยนรหัสตั้งต้น, Origin/JSON checks และ API authorization เดิม ไม่มีรหัสลับใน frontend ไม่มีสิทธิ์จากชื่อผู้เล่นหรือ localStorage

เพิ่มข้อมูลวันหมดอายุจากแถวเซสชันจริง ส่งให้หน้าเฉพาะ ID ผู้ดูแลและเวลา ไม่ส่ง token/hash ตรวจเซสชันทุก 15 วินาทีและเมื่อกลับเข้าแท็บ ปิดและ unmount ข้อมูลเมื่อครบเวลา ตรวจสิทธิ์ไม่สำเร็จ หรือ API ตอบ 401/403 เมื่อเชื่อมต่อไม่ได้จะไม่คงตารางผู้ดูแลเก่าบนหน้าจอ การออกจากระบบปิดข้อมูลก่อนส่งคำขอ และแจ้งหากคำขอยังไม่สำเร็จ การกลับเข้าใหม่ต้องผ่านเซิร์ฟเวอร์เสมอ กลไกหน้าจอเป็นส่วนเสริม ไม่แทน authorization ของ API

การเพิกถอนจากอีกเครื่องระหว่างไม่มีคำขออาจปรากฏบนหน้าจอจนถึงรอบตรวจถัดไป แต่ API ทุกคำขอยังคงตรวจสิทธิ์จริง ไม่มีการอ้างว่าเรียลไทม์ทันที

การตั้งค่ารหัสยังใช้สคริปต์ provisioning เดิมผ่านช่องรับแบบปิดบังบนเครื่องเซิร์ฟเวอร์ เจ้าของต้องตรวจ schema และเอกสาร deployment ก่อนดำเนินการ Agent ไม่ได้รัน provisioning หรือหมุนรหัสให้

## ข้อจำกัดและการตรวจโดยเจ้าของ

ระบบออนไลน์เดิมต้องมีฐานข้อมูล SQLite schema/ผู้ดูแล/HTTPS origin และ persistent storage ตามเอกสาร V6 ปัจจุบัน ไม่ได้เปลี่ยนผู้ให้บริการหรือ deploy ฐานข้อมูลนี้ในรอบ V7 การฝึกอิสระยังไม่มี telemetry หรือประวัติส่วนกลาง ผลแข่งขันยังขาด authoritative command replay สำหรับการรับรองจริง การอ้างอิงรุ่น/พอร์ตฝึกแสดงสถานะจากโค้ดเดิม ไม่ใช่การค้นเอกสารอุปกรณ์ยืนยันใหม่ในรอบนี้

เจ้าของควรตรวจตามลำดับ:

1. เปิด `/admin` แบบยังไม่ login ต้องไม่เห็นข้อมูล ตรวจรหัสผิด/จำกัดความถี่และการหมุนรหัสตั้งต้น
2. Login แล้วอยู่ `/admin` เห็นสามการ์ด สลับทุกห้องและเมนูย่อย URL ไม่เปลี่ยน ไม่มีรหัสรอบสอง
3. ห้องแข่งขัน: ข้อมูลจริง/ค้นหา/แบ่งหน้า/ข้อมูลว่าง/เครือข่ายขัดข้อง ตรวจการเปลี่ยนชื่อกับประวัติอันดับและสิทธิ์ความเป็นส่วนตัว ตรวจการยืนยัน ID และเหตุผลของคำสั่งสำคัญ
4. ห้องฝึก: จำนวนและรายการตรง configuration ทุกส่วนที่ยังไม่มี backend แสดงว่าไม่มี ไม่เกิดการแก้ห้องฝึกหรือข้อมูลผู้เล่น
5. ห้องภารกิจ: ครบห้าสถานที่ห้าระดับ รายละเอียด/ย้อนกลับ/ชุดสาย/เริ่มเล่นเดิม การดูไม่ผ่านภารกิจ และการเล่นตรวจไม่เพิ่มความคืบหน้าหรือบุญ ปุ่มกลับมาที่ `/admin`
6. เปิด bookmarks `/missions/admin`, `/admin/missions`, `/admin/players`, `/admin/overview`, `/admin/seasons` ทั้งตอน login และ logout ต้องลงท้าย `/admin` ไม่มีข้อมูลแอดมินใน URL เก่า
7. Logout/หมดอายุ/เพิกถอน/ตัดเครือข่าย: ปิดข้อมูลเดิม ลอง API ตรงโดยไม่มีสิทธิ์ต้องถูกปฏิเสธ ตรวจกลับหน้าและแท็บที่เปิดค้าง
8. ตรวจโปรไฟล์ผู้เล่นปกติ ภารกิจ การฝึกและ Arena เดิม รวมถึงปุ่มคีย์บอร์ดและหน้าจอ 1366×768, 1600×900, 1920×1080, Tablet/Mobile ด้วยตนเอง

ไม่ได้รัน lint/build/test/typecheck หรือ browser QA จึงยังไม่ยืนยันการคอมไพล์หรือการทำงานจริง ผลของ Git diff whitespace เป็นเพียงการอ่านการเปลี่ยนแปลง ไม่ใช่ผลทดสอบระบบ
