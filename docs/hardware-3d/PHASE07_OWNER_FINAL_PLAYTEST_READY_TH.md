# Phase 07 — Checklist ทดสอบรอบท้ายสำหรับต้า

สถานะ: พร้อมให้ทดสอบด้วยมือ หลัง internal checks ผ่าน ไม่ใช่รับรองว่า owner acceptance ผ่านแล้ว

## 1. โมเดลและ inspect

- [ ] เปิด Free Practice ตรวจ Samsung85/WM100 PLUS RX/TX ไม่เป็น WM300; PMX ไม่อ้าง Yamaha
- [ ] กด E ค้าง2วินาทีที่อุปกรณ์ exact/pending/generic และหัวสาย/adapter ดูชื่อ/หน้าที่/พอร์ต/สถานะ หมุน3Dดูหน้า-หลังได้ ไม่ค้าง
- [ ] แตะ E ยังคงหยิบ/ต่อ ไม่เปิด inspect แทน; ออกจาก inspect กลับเล่นได้
- [ ] ตรวจ AJA8หาง, Magewell MCX/BNC tail, SM58 grille, XLRเพศ, HDMI และ USB-C ไม่หลุดจากปลอก
- [ ] เครื่องรอยืนยันแสดง partial/owner-specific ไม่หลอกว่า exact; fiberไม่เดา LC/SC

## 2. โต๊ะทั้ง25ด่าน

ทำซ้ำ L1–L5 ของ XS, ST, AU, OUT, SP:

- [ ] จำนวนรวมของ venue เท่ากันทุกระดับ (10/16/29/18/45 ตามลำดับ) ช่องเก็บชิ้นเดียวกันคงที่
- [ ] เดินถึงด้านโต๊ะและหยิบชิ้นด้านหลังได้ ไม่มีวัตถุซ้อน/ลอย/จม; fixed install มี support/ทางเข้าถึง
- [ ] ของที่บทเรียนเริ่มติดตั้งไว้ยังอยู่สถานีตามเดิม ไม่ย้ายเพื่อทำให้ fault/บทเรียนเปลี่ยน
- [ ] หยิบ→วาง→ตั้งค่า→ต่อเอง ของสำรองไม่ทำให้ผ่านด่านอัตโนมัติ
- [ ] สายยังอยู่ระบบกระเป๋าเดิม หยิบหัว/ปลาย วาง ถอด ต่อใหม่/adapter ได้
- [ ] หลังต่อถูกต้องยังต้องตั้งค่า/ทดสอบ/ลงนาม; ถอดสายสำคัญต้องเสียสถานะผ่าน

## 3. Save และประสิทธิภาพ

- [ ] โหลดบันทึกก่อน Phase07 และบันทึกใหม่ กลับเข้า/resume ตำแหน่ง/การตั้งค่าไม่หาย
- [ ] Free Practice, admin level selection และ mission progression ยังเหมือนเดิม
- [ ] ลอง SP-05 ที่ของมากสุด เดิน/inspect/ต่อสายต่อเนื่อง ดูการตอบสนองบนเครื่องจริง
- [ ] ตรวจหน้าจอเล็ก/สัมผัสที่ใช้งานจริงและข้อความไทย ไม่มีป้ายทับปุ่มสำคัญ

ถ้าพบปัญหา ส่ง venue/level, ชื่ออุปกรณ์, ขั้นตอนก่อนเกิด, ภาพหน้าจอและ console error (ถ้ามี) ไม่ต้องลบ save หรือ reset project

ข้อจำกัดรุ่นและสิ่งรอยืนยันดู PHASE07_PENDING_AND_GENERIC_MODELING_TH.md; ยังไม่ควรตัดสิน high-fidelity 100% จากจำนวนภาพครบเพียงอย่างเดียว
