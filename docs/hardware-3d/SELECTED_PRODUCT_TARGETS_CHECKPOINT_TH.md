# จุดบันทึก: เลือกสินค้าอ้างอิงสำหรับโปรไฟล์ทั่วไป

อัปเดตหลังคำสั่งตรวจโต๊ะทุกห้องโดยไม่ควบคุมเล่น: ตอนนี้ผูกโมเดลภาพสำหรับ 27 โปรไฟล์แล้ว โดยมี photo geometry 22 โปรไฟล์, native HC-X2000 ที่ใช้ซ้ำ 1 โปรไฟล์ และ photo family renderer 4 โปรไฟล์; ทั้งหมดรวมในรายงาน `TABLE_AND_PHOTO_MODELS_ALL_ROOMS_TH.md` การผูกโมเดลครบไม่เท่ากับรับรองรายละเอียดโรงงานครบทุกส่วน

ภาพที่รวบรวมใหม่เป็น 58 records: รวม J-Iso, Hosa และ DeckLink เพิ่มเติม ส่วน GPP-105 คัดออกจากชุดที่ใช้จริงเพราะเป็นตัวต่อ TRS 6.35 มม. สองด้าน ไม่ใช่อะแดปเตอร์ 3.5 มม. ชุด MG12XU ใช้ J-Iso + YPP-136 แทนแผงบริการสมมติ รุ่น GAME Optical Fiber 12G ใช้รูปหัว LC duplex จากภาพคลังเดิม; คลัง generic optical ของอุปกรณ์จริงยังไม่เปลี่ยนสถานะ

ต้ามอบอำนาจให้เลือกสินค้าอ้างอิงที่เข้ากับระบบเดิม โดยไม่เปลี่ยนกติกาหรือรหัสอุปกรณ์แล้ว

## แยกสถานะให้ถูกต้อง

- มีตารางเป้าหมาย 27 โปรไฟล์ → 21 รายการสินค้า/ชุดประกอบใน `game/content/selected-product-targets.json`
- ตารางนี้คือการเลือกสินค้าเป้าหมายสำหรับงานภาพในเกม ไม่ใช่หลักฐานยืนยันอุปกรณ์จริงของเจ้าของ ปัจจุบันทั้ง 27 โปรไฟล์ผูกโมเดลแล้ว แต่ไม่ได้รับรองว่าเป็น CAD โรงงานหรือเหมือนจริงทุกจุด
- ไม่แก้ equipment registry, mission rules หรือ save schema เพื่อแอบให้ตรงสินค้า
- รุ่นที่ยืนยันไว้แล้วและคลังภาพเดิมยังอยู่ครบ ไม่ใช้ WM300 แทน WM100 PLUS
- เก็บ source snapshots แยกใน `art/reference/selected-products` ไม่ใส่ภาพผู้ผลิตใน public assets และยังไม่รับรองสิทธิ์เผยแพร่ภาพ

## บันทึกการทำงานช่วงก่อนหน้า (ประวัติ ไม่ใช่สถานะล่าสุด)

1. บันทึกแหล่งข้อมูลผู้ผลิตและข้อจำกัดของสินค้าเป้าหมายครบ 27 โปรไฟล์
2. เก็บภาพ/แผนผังเพิ่ม 52 ไฟล์จากหน้า Blackmagic, Omada, Whirlwind, Contour, Yamaha, Sony, Epson, Sennheiser, HP และ Dell; ตรวจภาพรวมแล้ว รายการ infographic และกล่องสินค้าแยกเป็น CONTEXT_ONLY ไม่เอามานับเป็นภาพพอร์ตหรือมิติ
3. ตรวจ SHA-256 เทียบหลักฐานเดิมก่อนบันทึก และเพิ่ม cache เพื่อไม่ดาวน์โหลดไฟล์เดิมซ้ำเมื่อรันต่อ
4. ปรับตัวควบคุม replay จากกล่องทั่วไปเป็นรูปทรงอ้างอิง ShuttlePRO v2: ปุ่ม 15 ปุ่ม วง shuttle และ jog wheel ขนาดยังประมาณจากภาพ ไม่ใช่มิติโรงงาน
5. จุด CTRL-REPLAY ยังคงเป็นจุดฝึกเชิงตรรกะ ไม่รับรองว่ามีช่อง CONTROL กายภาพบน Contour
6. ปรับ lavalier ให้มีสายติดตัวไปยังจุดต่อเดิม และนับสายดังกล่าวในพื้นที่จัดวาง
7. เริ่มปรับตัวถัง projector ตาม EB-FH52, กล้อง PTZ ตาม SRG-X400 และลำโพงตาม DBR12; สัดส่วนและตำแหน่งพอร์ตของโปรไฟล์เกมยังไม่ผ่านรับรองเป็นโมเดลโรงงาน
8. สร้าง reference pack แยก 21 ชุดสำหรับเป้าหมายใหม่ ครอบคลุม 27 โปรไฟล์ ทั้ง 21 ชุดมีไฟล์ภาพในเครื่องแล้ว โดย Panasonic HC-X2000 และ Shure SM58 ใช้ภาพคลังเดิมซ้ำ ไม่คัดลอกหรือดาวน์โหลดใหม่; คลัง 81 pack เดิมไม่ถูกเขียนทับ

## ผลตรวจช่วงก่อนหน้า (ประวัติ)

- ชุดทดสอบรวม 229/229 ผ่าน รวมเส้นทางภารกิจ 25 ด่าน; หลังปรับรายละเอียดภาพล่าสุด ชุดทดสอบเฉพาะ Hold-E/พอร์ต/โต๊ะ/เป้าหมายสินค้าผ่านอีก 9/9
- lint ผ่าน และ production build ผ่าน; ตรวจ TypeScript แยกผ่านก่อนการปรับ mesh สองรายการสุดท้าย และ build ล่าสุดตรวจ TypeScript ผ่านด้วย
- ตรวจภาพโมเดลจาก geometry ที่ export จริงผ่าน Blender แบบแยกฉาก ไม่แตะฉาก Blender ที่เจ้าของเปิดอยู่
- **ยังไม่ได้ตรวจภาพทุกสินค้าในเกมผ่าน browser และยังไม่ใช่งานปั้นสมบูรณ์ทั้งหมด** จึงไม่รายงานตัวเลขความสำเร็จการปั้นเป็น 100%
- ไม่มี commit/push, migration, seed หรือการแก้ .env.local; warning LF/CRLF เป็นคำเตือนปกติของ Windows

## ข้อจำกัดและการแก้ความคลาดเคลื่อน

- MG12XU ไม่มีช่อง STREAM/AUX stereo 6.35 มม. ช่องเดียวแบบโปรไฟล์เกม จึงแสดงชุดภายนอก Radial J-Iso + Hosa YPP-136 จากหลักฐานผู้ผลิต โดยไม่ใช้ PHONES แทน LINE และไม่เรียก mono AUX ว่า stereo
- EM 100 G4 มี XLR แต่ EK 100 G4 แบบติดกล้องใช้ขั้วคนละชนิด ต้องไม่ปนภาพหรือรุ่น
- MINI 6 แบบมี W1 เป็นออปชันแยก ไม่ยืนยันจำนวนขาจากภาพเล็ก และไม่เปลี่ยนเป็น Dante stagebox
- Optical Fiber 12G ต้องมี optical SFP ที่เข้าคู่กัน การเลือกชุด GAME ไม่ยืนยันชุด FIB-SDI เครื่องจริงของเจ้าของ
- Replay ใช้เวิร์กสเตชัน + DeckLink/vMix และ Contour เข้า host ทาง USB ไม่วาดสาย CONTROL ปลอมเชื่อม Contour กับ appliance โดยตรง
- เก็บภาพครบ/เลือกเป้าหมายครบ ≠ ปั้นครบ ≠ ผ่านตรวจภาพจริงในเกมครบ ทุกสถานะต้องตรวจแยก

## สถานะปัจจุบันและงานตรวจที่ยังไม่ทำ

ผูกภาพแสดงผลครบ 27 โปรไฟล์แล้ว ตรวจ geometry ผ่านภาพเรนเดอร์แยกฉากและทดสอบข้อมูลทุกด่าน โดยไม่เปลี่ยนพอร์ตเชิงตรรกะของภารกิจ รายละเอียดที่ภาพไม่ยืนยันยังเป็นค่าประมาณ ไม่รับรองสกรู วงจรภายใน ตัวอักษรเล็ก และ pinout ที่มองไม่เห็น ยังไม่ได้ควบคุมเล่นหรือวัด FPS ตามคำสั่งต้า ผลรอบล่าสุดอ่านจาก TABLE_AND_PHOTO_MODELS_ALL_ROOMS_TH.md และ FINAL_TABLE_PHOTO_IMPLEMENTATION_TH.md ไม่ใช้ตัวเลขทดสอบเก่าในส่วนประวัติ
