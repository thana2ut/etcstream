# Phase 05 · จัดอุปกรณ์รวมของแต่ละสถานที่ลงโต๊ะเตรียม ครบ 25 ด่าน

วันที่: 2026-10-21 · ยังไม่ได้ commit · **ตรวจระดับซอร์สและเทสต์อัตโนมัติเท่านั้น ยังไม่ได้เปิดดูในเบราว์เซอร์ (เจ้าของจะทดสอบเอง)**

## หลักการ
- **สต็อกหลักของแต่ละสถานที่:** ฟังก์ชัน `venueStock(scale)` ใน `game/training/venue-scenarios.ts`
  - คำนวณจาก `STAGES` ปัจจุบันทั้ง 5 ระดับ แล้วรวมอุปกรณ์แบบไม่ซ้ำ (union ของ instance id)
  - ทุกระดับของสถานที่เดียวกันจึงมีอุปกรณ์ชุดเดียวกันในห้อง
- **จำนวนเครื่อง:**
  - instance คือเครื่องจริงแต่ละตัว เช่น cam1–cam6 หรือ mic1/mic2 จำนวนจึงเท่ากับจำนวนสูงสุดที่ระดับใดระดับหนึ่งใช้พร้อมกัน
  - ไม่มีการเสกเครื่องซ้ำต่อระดับ (มีเทสต์ตรวจ)
- **เครื่องที่ระดับนี้ไม่ใช้:** ติดธง `stockOnly`
  - แสดงด้วย renderer 3D จริงตัวเดียวกัน ได้แก่ Blackmagic 14 รุ่น, AJA พร้อม breakout, Magewell SDI (MCX + สายหาง BNC), SM58 และ GLB เดิม ส่วนโปรไฟล์ GENERIC ยังใช้ renderer generic ที่ติดป้ายไว้
  - หยิบ ถือ หมุน วาง ตรวจดู และเสียบสายได้
  - ไม่นับในเป้าหมาย ไม่ถูกต่อสายไว้ล่วงหน้า และไม่อยู่ในลายเซ็นเซฟ
- **ตำแหน่งเริ่มต้นของสต็อก:**
  - เครื่องที่ยกได้ (พกพาได้ หรือเป็นอุปกรณ์ตั้งโต๊ะขนาดไม่เกิน 65 ซม. ตามขนาดจริง) เริ่มบนโต๊ะเตรียม `layout.equipment` ผ่าน `packStorage`
  - `packStorage` เรียงตามหมวดเดิม: ภาพ → เสียง → ควบคุม/สลับภาพ → จอ/บันทึก/จับภาพ/เครือข่าย → อื่น ๆ และวางเป็นแถวไม่ทับกัน
  - เครื่องใหญ่หรือโครงสร้างติดตั้ง (กล้องบนขาตั้ง, ลำโพงบนขาตั้ง, จอ, แร็ก/CCU, router, stage box, CFC ที่ติดท้ายกล้อง) อยู่ที่สถานีติดตั้งประจำของห้อง เป็นจุดเดิมทุกระดับ
- **โต๊ะเตรียมที่ใช้:** โต๊ะ `equipmentPrep` จากงานก่อน ไม่ได้ออกแบบใหม่
  - XS: `xs-equipment-prep`
  - ST: `sm-equip`
  - AU: `m-equipment-prep`
  - OUT: `l-equipment-prep`
  - SP: `xl-equipment-prep`
  - ชื่อหมวดภาษาไทยอยู่บนป้ายโต๊ะเดิม
- **สายยังอยู่ในระบบกระเป๋าเดิม:** ไม่ได้วางสายบนโต๊ะ
