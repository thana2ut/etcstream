## ข้อจำกัด
- **รอบนี้ไม่ได้เปิดเบราว์เซอร์ตามที่เจ้าของสั่ง:** ผลทั้งหมดมาจากพิกัดและเทสต์ ไม่ใช่การมองเห็นฉากจริง
- **การตรวจด้วยเบราว์เซอร์ในรอบก่อน (ก่อนเจ้าของสั่งหยุด):** ทำเฉพาะ SP-1 และ Free Practice บางส่วน ได้ผลดังนี้
  - เข้าห้องได้
  - หยิบ/วาง ATEM 2 M/E ได้
  - ระบบตรวจกระเป๋าเตือนเมื่อจำนวนสายผิด
  - พบและแก้แล้ว 3 จุดตามตารางด้านบน
- **ห้อง SP มีโมเดลจำนวนมาก (45 เครื่องในทุกระดับ):** ยังไม่ได้วัดเฟรมเรตบน iPhone
- **ป้ายหมวด:** ยังไม่ได้เพิ่มป้ายหมวดย่อยแยกรายชิ้นบนโต๊ะ ใช้ป้ายรวมของโต๊ะเดิม (เช่น "ภาพ / ควบคุม / เสียง") เพื่อไม่ให้ฉากรก
- **หลักฐานฮาร์ดแวร์ที่ยังขาด:** LC/SC ของ FIB-SDI-LINK, เพศหัว SMPTE ในสาย, หัว multicore, เพศปลาย BNC ของ ACC00050, ภาพด้านปลาย AJA และรุ่นย่อย SM58
