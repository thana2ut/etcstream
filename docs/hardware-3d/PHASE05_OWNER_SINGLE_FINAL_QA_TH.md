# Phase 05 · ทดสอบรับงานครั้งเดียว (เจ้าของ)

> งานในโค้ดเสร็จและผ่านการตรวจภายในระดับโค้ดแล้ว แต่ยังไม่มีใครเล่นจริง ให้เจ้าของทดสอบตามรายการนี้

1. **XS-1 → XS-5:**
   - ATEM Mini Pro / Studio Camera 4K Plus G2 อยู่บนโต๊ะเตรียมข้างผนัง
   - HDMI OUT ต้องตั้งเป็น PROGRAM เองก่อนจะผ่าน
2. **ST S-1 → S-5:**
   - Yamaha HS5 และ Magewell HDMI แสดงเป็นโมเดลจริง
   - อุปกรณ์ GENERIC มีป้าย "จำลอง"
3. **AU M-1 → M-5:**
   - M-5 Magewell SDI เป็นกล่องสีเงิน มีสายหางสีดำ ปลาย BNC
   - เสียบ SDI ที่ปลาย BNC ได้ แต่เสียบที่ขั้ว MCX บนตัวเครื่องไม่ได้
4. **OUT L-1 → L-5:**
   - L-4/L-5 AJA 3G-AMA มีสาย breakout
   - เสียบเสียงที่ XLR Input A/B ได้ ส่วน Output (ตัวผู้) เสียบไม่ได้
5. **SP XL-1 → XL-5:**
   - XL-2/4/5 SM58 นอนบนโต๊ะ เสียบ XLR ที่ท้ายด้าม
   - ห่วงโซ่ไฟเบอร์ CFC→SFC ยังถูกต้อง
6. **ตรวจสั้น ๆ:**
   - Free Practice
   - Admin เติมสายอัตโนมัติ
   - ออกจากด่านแล้วโหลดเซฟ M-5 ที่เล่นค้างไว้เดิมต้องโหลดได้
   - เล่นบน iPhone/iPad แบบสัมผัส
7. **หัวสาย (รอบที่ 2):**
   - หยิบสายแต่ละชนิดจากกระเป๋า แล้วดูว่ารูปหัวตรงชนิดและขนาดสมส่วนกับช่องเสียบ
   - สายไฟเบอร์กล้อง SP เป็นหัวโครเมียม SMPTE มีแถบแดง
   - สาย Fiber Link OUT เป็นหัวเทา-เหลืองแบบ generic
   - CTRL-REPLAY เป็นวงแหวนสีม่วงกับเส้นโปร่งแสง ไม่ใช่ปลั๊กจริง
   - หัวสายใน Free Practice เปลี่ยนรูปทรง แต่เสียบได้เหมือนเดิม
