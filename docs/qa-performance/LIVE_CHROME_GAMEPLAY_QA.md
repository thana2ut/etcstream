# รายงาน Chrome Gameplay QA

วันที่ 20 ตุลาคม 2026 — รายงานนี้สืบต่อรอบ ST-01 และรอบผู้ดูแลครบ 25 ด่าน คำขอล่าสุดให้เจ้าของเล่นจบด้วยตนเอง จึงไม่บังคับให้ตัวแทนจบทั้ง 25 ด่าน และไม่เปลี่ยนสถานะภายในเพื่อสร้างผลผ่าน

## วิธีตรวจและการรักษาข้อมูล

ใช้ Chrome extension แท็บเฉพาะ localhost:3000, dev server เดิม `npm run dev`; ตรวจหน้าจัดสาย → บทนำ → เริ่มฉากจริง → C ใบงาน/อุปกรณ์ของทุกระดับ ผ่าน `/missions/admin` และฟอร์มที่ได้รับอนุญาต UI ไม่มีโปรไฟล์ทดสอบแยก ใช้ผู้ฝึกเดิมโดยไม่ปลดล็อกผ่านข้อมูลเซฟ ไม่เก็บรหัสผ่านและไม่ถ่ายภาพช่องรหัส ความก้าวหน้าท้ายรอบยังสตูดิโอ 1/5 ระดับ (`qa-evidence/admin-final-progress-preserved.png`)

## ลูปที่ทดลองจบจริง

ST-01 รอบก่อน: เข้าด้วยกระเป๋าว่าง เดินหยิบ HDMI สองเส้นจากชั้น ต่อ Camera OUT → Switcher IN1 และ MV OUT → TV HDMI IN ด้านหลัง; ปฏิเสธ OUTPUT→OUTPUT; เมื่อเครื่องปิดแม้สายครบก็ไม่มีภาพ; ตั้งไฟ/กรอบภาพ/PROGRAM/จอและรูปแบบแล้วทดสอบครบ ถอดกล้องแล้วสัญญาณและผลทดสอบถูกล้าง ต่อคืนแล้วรับรองไม่ได้จนทดสอบใหม่; รับรอง 100/100 และ ST-02 ปลดตามการเล่นจริง ภาพ 04–12 และ 14 ประกอบได้ ส่วนภาพ 13 สองไฟล์ว่าง ไม่ใช้เป็นหลักฐานภาพผลสำเร็จ

## Console / asset / ประสิทธิภาพ

พบคำเตือน THREE.Clock deprecated และ Rapier init deprecated parameters ใน warn/error ที่ดึงมาไม่มี error ไม่ได้เก็บผลเครือข่ายของทุก asset และไม่ได้วัด FPS จึงไม่รับรองว่าไม่มีปัญหา asset หรือประสิทธิภาพทุกจุด ภาพเริ่มฉากครบทุกระดับแสดงว่า render ฉากได้ ไม่ใช่หลักฐานว่าโมเดลทุกชิ้นเดินถึงได้

## การตรวจที่ยังต้องทำเอง

เดินอ้อมทุกพอร์ต/ชั้นสายทุกแถว, ยกและวาง F/หมุน T ทุกเครื่องพกพา, โหลดสายชุดใหญ่, เล็งพอร์ตที่อยู่หลังตู้, ทดสอบเสียงและภาพจริงทุกสาขา/ทุก fault variant/เซฟซ้ำ, native pointer lock และ responsive ทุกขนาดจอ โดยใช้ MISSION_25_OWNER_MANUAL_TEST_CHECKLIST_TH.md

ไม่เปลี่ยน Free Practice Room01; ไม่ได้เล่นทดสอบห้องอิสระซ้ำในรอบนี้ การตรวจโค้ดว่ากิ่งเดิมยังอยู่ไม่เท่ากับผลเล่นผ่าน

ผลคำสั่งจริงอยู่ qa-evidence/admin-final-checks.md; ชุดรวมยังมีกรณีเดิมไม่ผ่าน 19 รายการ แยกสาเหตุใน qa-evidence/admin-regression-triage.md
