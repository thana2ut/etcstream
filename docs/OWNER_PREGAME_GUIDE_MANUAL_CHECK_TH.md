# เช็กลิสต์ตรวจหน้าคำชี้แจงและหน้าก่อนเล่น

- [ ] **หน้าบรีฟห้องฝึกอิสระ:** เปิดห้องฝึกอิสระ → หน้าบรีฟใช้การ์ด 4 ใบหน้าตาแบบเดียวกับหน้าบรีฟภารกิจ
  - การ์ด: ห้องฝึกอิสระคืออะไร / เป้าหมายการฝึก / สิ่งที่ผู้เล่นจะทำ / ข้อควรรู้ก่อนเริ่ม
  - ไม่มีรหัสด่านหรือรายการคู่พอร์ต
- [ ] **หน้าบรีฟภารกิจ:** ยังเป็นการ์ดแบบไม่เฉลยเหมือนเดิม
- [ ] **แท็บคำชี้แจง:** หน้าแรก → ก้าวเข้าสู่เส้นทาง → หน้าคำชี้แจง → กดดูครบ 5 แท็บ
  - ข้อความภาษาไทยอ่านได้ ไม่มีตัวอักษรเพี้ยน
  - ปุ่มในแท็บวิธีเล่นตรงกับที่เล่นจริง (E, E ค้าง 2 วินาที, F, T, 1/2, R, C)
- [ ] **ปุ่มย้อนกลับ:** `ย้อนกลับ` ในหน้าคำชี้แจงกลับไปหน้าแรก
- [ ] **ปุ่มปิดจารึก:** `ปิดจารึกและดำเนินต่อ` ไปหน้าจารึกชื่อหรือหน้าต้อนรับ
- [ ] **ไม่แสดงอีก:** ติ๊ก "ไม่แสดงอีกในครั้งถัดไป" แล้วปิด → เข้าใหม่ หน้าคำชี้แจงไม่แสดงอีก
- [ ] **X หน้าคำชี้แจง:** ไม่มีปุ่ม X วงกลมที่มุมขวาบนแล้ว และส่วนหัวไม่มีช่องว่างแปลก
- [ ] **X กล่องเตือนสีแดง:** หน้าเตรียมสาย → จัดกระเป๋าผิดแล้วกดเข้าสู่ด่าน
  - ไม่มีปุ่ม X ที่มุมขวาบน
  - คลิกพื้นหลังแล้วกล่องไม่ปิด
  - กด `กลับไปจัดกระเป๋า` แล้วกล่องปิด และของในกระเป๋ายังอยู่
- [ ] **ปุ่ม ✕ ในช่องกระเป๋า:** ยังนำสายออกได้ทีละเส้น
- [ ] **เล่นต่อ:** มีห้องที่ยังทำค้าง → กลับหน้าสำนัก → เข้าด่านเดิม → หน้าต่าง "พบการฝึกที่ยังดำเนินอยู่" ยังทำงาน
- [ ] **ความลื่น:** เปิด/ปิดหน้าคำชี้แจง สลับแท็บ และเลื่อนเนื้อหา บนเดสก์ท็อป iPad และ iPhone
  - ไม่ควรหน่วงหรือค้าง
  - หลังปิดหน้าต่าง เมฆบนหน้าแรกต้องลอยต่อตามปกติ
- [ ] **เมฆ:** ลอยต่อเนื่องไม่มีรอยต่อหรือกระตุกตอนวนรอบ (เปลี่ยนวิธีเลื่อนเป็น transform)

**ข้อมูลที่ควรเก็บถ้าพบปัญหา:** อุปกรณ์และเบราว์เซอร์ หน้าและแท็บที่เปิดอยู่ ภาพหน้าจอ และ (ถ้าทำได้) DevTools → Performance บันทึกช่วงที่หน่วง
