## การจัดให้พอดีจอ

แทนระยะขอบการ์ดเดิมที่สะสมกับพื้นที่ shell ด้วย grid สองแถว: แถบกลับสำนักและพื้นที่วางการ์ดกึ่งกลาง ใช้ `min-height: 100dvh` แบบรวม padding ด้วย border-box ความกว้างการ์ดสูงสุด 520px และความสูงจากเนื้อหาจริง ใช้ระยะและขนาดด้วย clamp/dvh ลดช่องว่างในหน้าต่างเดสก์ท็อปสูงไม่เกิน 740px

ไม่ได้กำหนดความสูงการ์ดแบบตัดเนื้อหา ไม่ซ่อน overflow ของหน้า และไม่สร้างแถบเลื่อนในกล่อง หากหน้าต่างสั้นมาก ซูมข้อความ หรือข้อความผิดพลาดยาวเกินพื้นที่ ยังให้เลื่อนทั้งหน้าได้เพื่อเข้าถึงทุกปุ่ม เป้าหมายปกติคือ 1366×768, 1536×864, 1600×900 และ 1920×1080 แต่ยังไม่ได้ยืนยันการแสดงผลจริงที่ขนาดเหล่านี้ตามคำสั่งเจ้าของ

## การยืนยันสิทธิ์เดิม

ไม่ได้แก้ไฟล์ backend, API, hash, cookie, server session หรือค่ารหัสหลัก ขั้นตอน entry-reset ก่อนอนุญาตกรอก → ส่ง login/rotate → ตรวจฝั่งเซิร์ฟเวอร์ → เปิด UnifiedAdmin เดิมยังคงอยู่ การคืนจากประวัติเบราว์เซอร์ยังตั้งประตูใหม่ ไม่เพิ่มการจำรหัสหรือสิทธิ์ผ่าน localStorage ไม่เปลี่ยนเส้นทางหลังล็อกอิน ข้อมูลผู้เล่นและระบบเกมไม่ได้แก้

## ส่งต่อให้ต้าตรวจเอง

- หน้าปกติทั้งสี่ขนาดเป้าหมาย: ตราประตู ชื่อ ช่องรหัส ปุ่ม และข้อความช่วยอยู่ครบ ไม่มีแถบเลื่อนหรือการตัดขอบ
- การกรอกรหัสผิด/กำลังโหลด/เชื่อมต่อไม่ได้/เปลี่ยนรหัสตั้งต้น: ข้อความชัดเจนและปุ่มใช้งานได้
- แป้น Tab, Enter และลิงก์กลับสำนักทำงานตามเดิม จุดโฟกัสเห็นชัด
- รหัสถูกต้องเปิดสามห้องเดิม ออกจากระบบแล้วเข้าจากภายนอกใหม่ต้องถามรหัสหลัก
- บนมือถือหรือขยายข้อความ ทุกเนื้อหายังเข้าถึงได้ แม้จำเป็นต้องเลื่อน

ไม่ได้รัน tests, lint, typecheck, build, browser automation หรือ gameplay verification ไม่แก้ `.env.local` ไม่รัน migration/seed ไม่ commit/push/deploy ไม่มีภาพผลลัพธ์หลังแก้และไม่อ้างว่าผ่านการทดสอบแล้ว
