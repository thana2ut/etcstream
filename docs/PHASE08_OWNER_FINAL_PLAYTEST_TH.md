# Phase 08 — เช็กลิสต์ทดสอบครั้งสุดท้ายของต้า

- [ ] เปิดหน้าจัดสายทุกห้อง: เห็นสายกายภาพครบทุกหมวดและหัวแปลง โดยไม่เห็น CTRL-REPLAY
- [ ] ใส่สายผิด สายขาด สายเกิน: เห็นคำเตือนสีแดงตรงกลางและของในกระเป๋ายังอยู่
- [ ] ใส่สายตรงตามด่าน: เข้าฉากได้; ด่าน L4 ที่ต่อสายไว้แล้วไม่บังคับแพ็กเพิ่ม
- [ ] เปิดแต่ละห้อง XS/ST/AU/OUT/SP ตรวจการต่อพอร์ต การตั้งค่า และการตรวจรับจากกราฟจริง
- [ ] Admin เข้าด่านทั้ง 25 โดยได้เฉพาะสายจำเป็น; Free Practice ทดลองสายได้โดยไม่ติด strict gate
- [ ] ตรวจหน้าจัดสายบนมือถือและแท็บเล็ต พร้อมปุ่มดูรายละเอียด
- [ ] กลับเข้าเกมและโหลดเซฟเดิม ตรวจความคืบหน้าและรหัสอุปกรณ์เดิม
- [ ] OUT ยังเคารพคำเตือนฟ้าผ่าและ GO/NO-GO; SP แยก Replay control จากสายภาพ; AU ดูสายหาง MCX/BNC; OUT ดู AJA breakout
