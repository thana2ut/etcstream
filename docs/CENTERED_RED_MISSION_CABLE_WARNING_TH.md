## 2. แต่ละกรณี
| กรณี | ป้ายสั้น | ข้อความ |
|---|---|---|
| กระเป๋าว่าง | กระเป๋ายังว่าง | กระเป๋ายังว่างอยู่ โปรดเลือกสายที่เหมาะสมก่อนก้าวเข้าสู่ด่าน |
| สายไม่ครบ | เลือกสายไม่ครบ | สายที่เลือกยังไม่ครบตามเงื่อนไขของภารกิจ โปรดกลับไปตรวจสอบกระเป๋าอีกครั้ง |
| ชนิดผิด / มีสายเกิน | ชนิดสายไม่ตรง | ชนิดหรือจำนวนสายที่เลือกไม่ตรงกับภารกิจ โปรดจัดกระเป๋าใหม่ก่อนเข้าสู่ด่าน |
| จำนวนเกิน / เกินคลัง | จำนวนสายไม่ถูกต้อง | (ข้อความเดียวกับแถวบน) |

หัวข้อของทุกกรณีคือ `ค่ายกลสายสัญญาณยังไม่สมบูรณ์` และปุ่มหลักคือ `กลับไปจัดกระเป๋า` คำเตือนไม่บอกชื่อสายหรือจำนวนที่ถูกต้อง

ด่านที่ไม่ต้องใช้สายเลย (AU-04) เข้าได้ด้วยกระเป๋าว่างตามกฎเดิม

## 3. การกันเข้าด่านเมื่อจัดสายไม่ถูก
- ปุ่ม `เข้าสู่ด่าน` ในโหมดภารกิจกดได้เสมอ แม้กระเป๋าว่าง เพื่อให้ผู้เล่นเห็นคำเตือน
- ทุกครั้งที่กด ระบบตรวจกระเป๋าใหม่กับด่านปัจจุบัน
  - ไม่ผ่าน: เปิดคำเตือน 1 กล่อง (กล่องที่เปิดอยู่จะไม่ซ้อนอีก) ไม่ไปหน้าเล่น และไม่แก้ของในกระเป๋า
  - ผ่าน: เข้าด่านทันทีผ่าน `onConfirm` เดิม
- `app/play/page.tsx` ยังตรวจซ้ำอีกชั้นก่อนเข้าห้อง
- กันการกดซ้ำตอนกำลังเข้าด่านด้วย `entering` ref

## 4. หน้าตาและการใช้งาน
- **ฉากหลัง:** ม่านมืดโปร่งแสงเบลอเต็มจอ (`z-index` สูงสุด) อยู่เหนือแถบล่าง HUD และ canvas
- **กล่องเตือน:**
  - กว้าง `min(720px, 90vw)` อยู่กลางจอทั้งแนวตั้งและแนวนอน
  - พื้นสีกรมท่า ไล่เฉดแดงเข้มด้านบน กรอบแดงเรืองแสงพร้อมเส้นทองด้านใน
  - ไอคอนตราผนึกแตกสีแดง หัวข้อสีแดงอ่อน เนื้อความสีครีม (ไม่ใช่ตัวแดงบนพื้นแดง)
- **มือถือ:** ความสูงไม่เกิน `100dvh − 32px` ถ้าล้นจะเลื่อนภายในกล่อง เว้นขอบตาม safe-area ขนาดตัวอักษรใช้ `clamp` และระยะบรรทัด 1.5–1.75 สำหรับภาษาไทย
- **การเข้าถึง:** `role="alertdialog"`, `aria-modal`, `aria-labelledby`/`aria-describedby`
- **คีย์บอร์ด:**
  - โฟกัสเริ่มที่ปุ่ม `กลับไปจัดกระเป๋า`
  - Tab วนอยู่ในกล่อง
  - ปุ่มอื่นด้านหลังไม่ทำงานระหว่างกล่องเปิด
- **ปิดได้ด้วย:** Esc, ปุ่ม ✕, ปุ่มหลัก หรือคลิกฉากหลัง (การคลิกฉากหลังทำได้แค่ปิด ไม่เข้าด่าน) ปิดแล้วโฟกัสกลับไปที่ปุ่ม `เข้าสู่ด่าน`

## 5. สิ่งที่ไม่เปลี่ยน
การ์ดสาย หมวด แผงรายละเอียด ช่องกระเป๋า หน้าตาปุ่มเข้าด่าน และข้อความแนะนำท้ายหน้า ยังเหมือนเดิม ห้องฝึกอิสระยังใช้กฎ "มีสายอย่างน้อย 1 เส้น" แบบเดิมและไม่มีกล่องเตือนนี้ ระบบผู้ดูแลไม่ได้แก้ แต่เข้าด่านผ่านหน้าเตรียมสายเดียวกัน จึงได้คำเตือนนี้ด้วย
