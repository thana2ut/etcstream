# แก้หอภารกิจแอดมินล้นขอบและเสียสมดุล

อ้างอิงภาพ `codex-clipboard-c8e8dde7-c6b0-4c1e-ba8c-05cd830cd9f4.png`

## สาเหตุจากซอร์ส

`.fantasy-viewport` ใน `app/cultivation-theme.css` กำหนด `width: 100vw` และ `max-height: 100dvh` สำหรับหน้าหอภารกิจเต็มจอ แต่ส่วนแอดมินนำหอภารกิจเดียวกันมาฝังในกรอบที่แคบกว่าหน้าจอ โดยไม่ได้ยกเลิกความกว้างดังกล่าว ทำให้กรอบและกริดกว้างเกินพื้นที่แม่ ตรงกับภาพที่การ์ดบท 03 หลุดขอบขวา

## แก้เฉพาะ app/admin/admin.css

- กำหนดหอภารกิจที่ฝังให้กว้าง 100% ของกรอบแม่ รวม padding และ border ในความกว้าง ยกเลิกเพดานความสูงจากหน้าเต็มจอ
- กำหนดเนื้อหา กริด และการ์ดให้ย่อได้ภายในกรอบจริง ไม่ใช้ overflow hidden กลบเนื้อหา
- คงการ์ด 3+2 แถว โดยแถวล่างอยู่กึ่งกลาง ใช้ช่องว่างเท่ากันและความสูงแถวสม่ำเสมอ
- ปรับพื้นที่ภาพ ระยะชื่อบท และระยะภายในการ์ดเพื่อให้ได้สัดส่วนกับความกว้างใหม่

ไม่แก้หน้าล็อกอิน หอภารกิจสาธารณะ ข้อมูลด่าน การเลือก 25 ระดับ การเล่นตรวจ หรือระบบสิทธิ์
