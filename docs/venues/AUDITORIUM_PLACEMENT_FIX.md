# ปรับการจัดวางหอประชุมใหญ่

ขอบเขต: เฉพาะหอประชุมใหญ่ ไม่เปลี่ยนภารกิจ การควบคุม กระเป๋า หรือความก้าวหน้า

## สาเหตุและการแก้ไข
- โน้ตบุ๊กหันเข้าผู้ชมและไม่มีที่นั่ง: หมุนเข้าฝั่งผู้นำเสนอ จัดกึ่งกลางโต๊ะ เพิ่มเก้าอี้พร้อมตัวกั้นการเดิน โดยมีช่องว่างจากเวทีและโต๊ะ
- คอมพิวเตอร์ชิดขอบโต๊ะและเราเตอร์อยู่ระดับพื้น: ย้ายอุปกรณ์เข้าบนพื้นที่โต๊ะจริง จัดเครื่องเสียงและหูฟังให้พ้นขอบ
- แผงขาเข้าโปรเจกเตอร์อยู่ต่ำกว่ากล่อง: ยกให้วางบนกล่องจริง ย้ายกล่องข้างเคียงให้มีช่องว่างเพิ่ม
- ต้นไม้บังจอด้านข้าง: ย้ายเข้าช่วงผนังระหว่างจอ
- ไฟใกล้เพดานเกิดจุดจ้า: ใช้แสงเติมกว้างและกำหนดเป้าไฟเวทีด้วย Object3D ที่อยู่ในฉากจริง
- ใช้โมเดลจอจากรหัสอุปกรณ์ในหอประชุมเพื่อรองรับชื่อไทย และปรับพอร์ตให้ตรงแผงหลัง จอโน้ตบุ๊กแสดงตามสถานะไฟและสัญญาณจริง
