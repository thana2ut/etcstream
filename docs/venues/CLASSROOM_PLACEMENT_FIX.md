# ปรับการจัดวางห้องเรียน

แก้เฉพาะห้องเรียน โดยคงภารกิจ การควบคุม และความก้าวหน้าเดิม

- แสดงกล้องประจำห้องในด่านแรก ด่านที่มีกล้องในภารกิจใช้กล้องโต้ตอบเดิม โดยไม่แสดงตัวซ้ำ
- กล้องหันไปยังตำแหน่งผู้สอน และใช้จุดเดียวกับผังห้อง
- เปลี่ยนไฟขาตั้งที่ตัวครอบบิดเป็นแผงไฟทรงปกติ พร้อมขาตั้งและทิศทางจริง แยกแสงหลักและแสงเติม
- ลดแสงหน้าต่างที่จ้าเกิน และใช้แสงเพดานกว้างแทนไฟจุดที่ทำให้เกิดปื้นสว่าง
- หมุนโน้ตบุ๊กให้หน้าจอและแป้นพิมพ์หันเข้าหาผู้สอน พอร์ต HDMI หมุนตามเครื่อง
- เพิ่มแป้นพิมพ์และแผ่นสัมผัส หน้าจอโน้ตบุ๊กแสดงตามไฟเลี้ยงและสัญญาณจำลอง
- เพิ่มจอตรวจภาพจากอินพุตโปรเจกเตอร์ และแก้การจำแนกจอสำรองภาษาไทยเฉพาะห้องเรียน
- ขยับจุดกล้องเอกสารให้อยู่บนโต๊ะผู้สอน

## ไฟล์ที่แก้ในรอบนี้

- `components/game/environment/venue/classroom.tsx`
- `components/game/equipment/generic-device.tsx` — การปรับภาพใหม่จำกัดที่ layout ห้องเรียน
- `game/training/venue-layouts.ts` — ตำแหน่งเฉพาะห้องเรียน
- `game/training/sim/rooms.ts` — จุดกล้องเอกสารห้องเรียน
- `game/training/venue-scenarios.ts` — ตำแหน่งพอร์ตจอสำรองเฉพาะห้องเรียน
- `tests/venue-scenarios.test.mjs` — ตรวจทิศโน้ตบุ๊ก พอร์ต และกล้องทุกระดับของห้องเรียน

## การตรวจสอบ

- `npm run lint` และ `npm run build` ผ่าน
- `git diff --check` ผ่าน มีเพียงคำเตือน LF/CRLF ปกติบน Windows
- ทดสอบผ่าน 164/164 รวมการเล่นจบทั้ง 25 ด่าน การรับส่งภาพ และการเข้าถึงพอร์ต
- ตรวจภาพห้องเรียนจากฝั่งผู้สอน ฝั่งตะวันออก และมุมหน้าต่าง หลังโหลดฉากใหม่
- เปิดไฟและโหมดนำเสนอผ่านหน้าควบคุมจริง หน้าจอโน้ตบุ๊กแสดงสไลด์ตามสถานะจำลอง
- ไม่เปลี่ยนกฎภารกิจหรือเพิ่มแพ็กเกจ ไม่ commit, push หรือ deploy

## ข้อจำกัด

ภาพบนจอยังเป็นสัญญาณฝึกจำลองของระบบเดิม กล้องในด่านแรกเป็นกล้องประจำฉาก และเริ่มใช้เป็นอุปกรณ์ในภารกิจตั้งแต่ระดับที่กำหนด ต้ารีเฟรชเกมเพื่อโหลดตำแหน่งและแสงใหม่ได้เลย
