# จัดพื้นที่กิจกรรมกลางแจ้งให้ตรงป้ายและพร้อมฝึก

## สาเหตุ
ป้ายจุดกล้องและไฟเบอร์ยังอ้างตำแหน่งชุดเก่า ขณะที่บทเรียนใช้กล้อง A/B คนละฝั่งกับข้อมูลเดิม อุปกรณ์แสดงเฉพาะระดับที่ใช้งานจึงทำให้จุดประจำพื้นที่ว่าง โต๊ะควบคุมขนาดเดิมไม่รองรับตำแหน่งอุปกรณ์ทั้งหมด และโน้ตบุ๊กบนเวทีขาดโต๊ะรองรับ

## สิ่งที่ปรับเฉพาะพื้นที่กลางแจ้ง
- กล้อง A อยู่ตะวันออก กล้อง B อยู่ตะวันตก ใช้ตำแหน่งร่วมกันระหว่างฉาก ป้าย และระบบต่อสาย
- แสดงกล้อง B ในบทแรกและกล้อง C สำรองบนแท่นภาพรวม เมื่อกล้องเป็นอุปกรณ์ประจำบท ระบบใช้โมเดลที่โต้ตอบได้เดิม ไม่มีการวางโมเดลซ้อน
- ป้ายภาษาไทยใหม่ตรงกับกล้อง จุดพิธีกร ตู้รวมสัญญาณภาพ และจุดรับสตรีมทดสอบ เลิกใช้ป้ายไฟเบอร์ที่ไม่ตรงกับหลักสูตรปัจจุบัน
- เพิ่มโต๊ะรองโน้ตบุ๊กและตัวแปลงบนเวที หมุนโน้ตบุ๊กเข้าผู้นำเสนอ เพิ่มขาไมค์ ย้ายโต๊ะพ้นแนวลำโพงมอนิเตอร์
- ขยายโต๊ะควบคุมเป็น 5.2 × 1.3 เมตร อุปกรณ์วางอยู่ภายในขอบโต๊ะ เพิ่มที่นั่งผู้ควบคุมสองจุด
- ขยายหลังคาควบคุมให้ครอบคลุมตู้รวมภาพ โต๊ะ และจุดรับสตรีม เพิ่มหลังคาคลังอุปกรณ์ และตัวกั้นการเดินตามเสา กล้อง และเก้าอี้
- จอภาคสนามเลือกโมเดลจากชนิดอุปกรณ์แทนการเดาจากชื่ออังกฤษ พอร์ตอยู่ตรงแผงหลัง จอแสดงสถานะไฟและสัญญาณตามจริง
- เพิ่มมุมตรวจเฉพาะโต๊ะควบคุม กล้อง B และเวทีในโหมดตรวจฉาก
- รักษาภารกิจ คะแนน การควบคุม กระเป๋า และลำดับการปลดล็อกเดิม

## ข้อจำกัดและการตรวจรับ
- กล้อง C เป็นกล้องสำรองประกอบฉาก ไม่มีภารกิจ/พอร์ตฝึกเพิ่ม ส่วน A/B ใช้ระบบโต้ตอบเมื่อระดับนั้นกำหนดให้ใช้
- อุปกรณ์ที่ผู้ฝึกต้องหยิบมาติดตั้งยังเริ่มในคลัง ไม่จำลองว่าต่อสายหรือเปิดเครื่องสำเร็จแล้ว
- ภาพจริงตรวจ OUT-01 ส่วน OUT-02 ถึง OUT-05 ตรวจด้วยชุดทดสอบ ไม่ได้เดินเล่นด้วยมือครบทุกระดับ
- โมเดลใช้ของเดิมในโปรเจกต์ ไม่เพิ่มแพ็กเกจหรืออ้างว่าเป็นแบบผลิตภัณฑ์จริงที่ตรงรุ่นทุกชิ้น
- เปิดภารกิจกลางแจ้งใหม่เพื่อตรวจรับฉบับล่าสุดได้ ยังไม่เผยแพร่ขึ้นเว็บ
